### lojmIt lo'lu'taH
`EYAS_PORT=3200 ./bin/eyas start` pagh mIw yInarghmoH.

### UI tu'lu'be'
`bun run build:web` (taghDI' nIteb Qap — `EYAS_SKIP_WEB_BUILD=1` tu'lu'be'chugh).

### /docs 404
`bun run docs:build` pagh `EYAS_SKIP_DOCS_BUILD` Hutlh 'ej yItaghqa'. tev: `packages/docs`.

### De' nuqDaq?
