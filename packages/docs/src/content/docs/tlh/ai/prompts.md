**nuq 'oH.** Hoch tlheD mu'tlhegh patlh boq, wa' blobbe'. **Master** Hoch qa' (ngoQ So'lu'). **Qu' Segh** 'ej **Qu'** QapchoH. **ja'chuq** He-nIvbogh. ghoqwI'pu' **pat mu'tlhegh** ghaj. composer **Prompt Enhancer** wa'logh chovnatlh neH.

**Hemey:** `/prompts` (nav **mu'tlheghmey**), `/prompt-settings`.

## ghorgh yIlo'

- juH ghogh (**personality** choHlaH) ngoQ So'lu'bogh tlhe'be'.
- Qu' Segh brief lInlaH (foS pat legh; chIm = Segh jeS, `+` = chel, latlh = qa'; qon `AGENTS.md` ghItlh).
- wa' Qu' Segh pab latlh Qu'Daq narghbe'.
- chovnatlh mach — Enhancer, nI' patlh choHbe'.

## motlh mIw

1. **mu'tlheghmey** (`/prompts`): **Master / Qu' Segh / Qu' / ja'chuq**.
2. So'lu': **laD neH**. latlh: choH, chu'/chu'Ha', teq.
3. `/prompt-settings`: **personality** neH choHlaH. qon: `PATCH /prompts/master/personality`.
4. nI' brief: **Prompt coach** FormDaq, **lo'**.
5. wa'logh lo'wI' mu'tlhegh: **Prompt Enhancer** composervo'.
