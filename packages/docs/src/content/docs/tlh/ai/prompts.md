## mu'tlhegh QaD (ja'chuq qonwI'mey)

ja'chuq **ghItlhwI'** vo' poS. tlhegh **pat ghom** vaD **wa'logh** lo'wI' mu'tlhegh QaDmoH, Qu' Segh pongHommey, QaQ chov, puS/naQ DuHmey je.

naQ mIw raS: [ja'chuqmey — mu'tlhegh QaD](/docs/tlh/daily/conversations/#prompt-enhancer-dialog).

## mu'tlhegh ghojmoHwI' (qonlu'ta' qIbmey)

**mu'tlhegh ghojmoHwI'** moQmey **qonlu'ta'** mu'vaD Qu' SIv ghojmoHwI' poS — ja'chuq qonwI'mey jebe'.

| logh | nuqDaq | nuq QaDmoH |
|------|--------|------------|
| **Qu' Segh** | Qu'mey → Qu' Seghmey → mu'tlhegh | Seghvam Qu'mey luSuqbogh motlh lo'qa'laH |
| **Qu'** | Qu'mey → Qu' → mu'tlhegh | Qu' ja'chuqmey HochvaD vummeH Del (yuQ, tIgh, QapmeH chovnatlh) |
| **ghoqwI' pat** | ghoqwI'pu' → SeH → pat mu'tlhegh | ghoqwI' vummeH tIgh (ghogh 'oHbe', Qu' yuQ 'oHbe', wa'logh Qu' 'oHbe') |

### ghojmoHwI' ja'chuq SeHwI'mey

| SeHwI' | QIj |
|--------|-----|
| logh pongHom | **Qu' qIb** / **Qu' Segh qIb** / **ghoqwI' systemPrompt** |
| qonwI' / jang | nISwI' yIDel pagh qonwI' yIchel; **ngeH** qaSqa' |
| **QaQ N/10** | tetlh chov; **Hutlh** Hutlhbogh Dochmey tetlh |
| **cha' He yIchup** | puS + naQ DuHmey |
| **chuplu'bogh Del** | chelmeH wIv |
| **lo'** | qonwI' mIwDaq Del yIghItlh |
