## motlh mIw

1. tlhop **SeHmey** ghom **patHommey** → **cheltaHghachmey** (`/extensions`) yIpoSmoH.
2. **vum'egh chel boqmey** 'ej **latlh janmey lI'laHbogh** yIlaD. nav Hoch pong, chaw' Degh, mI', lo'wI', laH mI' 'ang.
3. vum'egh boq: **yIchel**. **chaw' QIn** yIlaD, ghIq **yIlaj 'ej yIchel** (pagh **qIl**).
4. chelta'DI', HoS SeHwI' **yIchu'** / **yImev**; Qaw' jan teq.
5. latlh boq: **GitHub** yIpoSmoH, **chu' paq** yItlha', SoH chel, chaw'Daj pabtaHvIS. EYAS SoHvaD ngeHbe'.

**chelta'** Degh 'ej woS chelta' mI' tu'lu'nIS.
