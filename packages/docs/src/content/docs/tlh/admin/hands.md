**Qu' 'oH.** ghopmey EYAS Hand lo'wI'pu' rar potlh 'oH — De'wI'mey SoH SeHbogh, CLI janmey, OS nIteb Qap, De'wI' lo' je De'wI'vamvaD nob. poH Hom rar mu' jan rar; Hand mey rarlu'bogh qach, 'aqroS, OS, laHmey, CLI/app jan mI' je 'ang. hopbogh SSH Daq ghobe', AI bej ghobe'.

## ghorgh yIlo'

- ghoqwI' CLI pagh De'wI' Qu' *SoH* Mac, Windows pagh LinuxDaq QapnIS, De'wI' Qap neHbe'.
- Hand lo'wI' chu' Dara' 'ej vagh tup ram mu' DapoQ.
- Hand rarlu''a' Dalegh, laH (**CLI**, **OS nIteb Qap**, **De'wI' lo'**), 'ej 'ar jan tu'.
- jan yIrarHa', vuvbe'chugh.

## motlh mIw

1. tlhop **SeHmey** ghom **pat chen** → **ghopmey** (`/hands`) yIpoSmoH.
2. **rar mu' yIchenmoH**. **rar mu'** tIn nargh; **5 tup qaSpu'DI' ram — Hand janDaq mu'vam yIghItlh**.
3. Hand lo'wI'Daq mu' yIghItlh. ramDI' navvamvo' mu' nargh.
4. **chu'qa'**, nav chu' leghbe'chugh.
5. qach · 'aqroS · OS, laH Deghmey, jan mI' yIchov, ghIq taH pagh **yIrarHa'**.

chIm: *Hand tu'lu'be'* / *rar mu' yIchenmoH 'ej EYAS Hand lo'wI' yIrar*. rarpu'DI' SuD qIn 'ej Hand id Hom.

## laHmey

rar mu'mey **300 lup** (vagh tup) 'ej nargh. chenmoH Qagh Qagh QIn 'ang.

Hand rarlu'bogh Hoch: pong, id Hom, `platform · arch · osVersion`, **N janmey**, mIw mI', **Qav legh** poH, laH Deghmey. qach Degh: Darwin, Windows, Linux (latlh motlh).

lo'wI' laHmey 'ang:

| Degh | Del |
|------|-----|
| **CLI** | ra' janmey De'wI'vamDaq |
| **OS nIteb Qap** | OS nIteb Qap |
| **De'wI' lo'** | De'wI' / computer-use |

janmey tu'lu'bogh **cli** pagh **app** (id, pong, He, mI' chaw'). navvam **mI'** 'ang, jan tetlh ghobe'.

**yIrarHa'** Hand tetlhvo' teq (MCP He teq je, rar mIwvetlh 'oHchugh). **chu'qa'** tetlh chu'qa'.
