## nuqDaq yIlo'

- bI'ellaH 'ej potlh Qu' poS
- wa' lI'bogh ja'chuq DaneH, Hoch qach bejbe'
- **jIH Daq**, **Qu' nav**, **qawHaq**, **ghoqwI'pu'** je chay' rar 'e' yIyaj

## yI'el 'ej jIH DaqDaq yIba'

UI yIpoSmoH (motlh **http://localhost:3100**). lIng pIn'a'Daq DachenmoHta'bogh potlh pIn **lo'wI' pong** 'ej **pegh mu'** yIghItlh, ghIq **yI'el** yIwuv.

**jIH Daq**Daq bIba' (`/`). HochvaD rapbogh chenmoH nav motlh, SoH choHpa'.

wej chovnatlh yIlegh wa'DIch:

- **tIq** — SoH poQ, QaptaH, loS, DaHjaj Huch, Qu'mey Qapbe'
- **qImnIS** — chaw', che'egh taHbe', ghoqwI' loS, poH-tlhejbe'; chovnatlhvo' ta'laH
- **ghoqwI'pu' QaptaH** — yIntaHbogh vum; **loS**, **taHqa'**, pagh **mev**

chenmoH nav DungDaq lIng chup tlhegh tu'lu'laH. repvamDaq yIlajHa'.

## ja'chuq yItagh

latlhDaq **ja'chuq chu'** yIwuv. chIm Dotlh jatlh **ja'chuq yItagh…**.

lI'bogh tlhob yIghItlh — chay' vumlu' DaneH, wuq, pagh tlha' DaneHbogh Qu'. ghItlhwI': **QIn yIghItlh… (Shift+Enter tlhegh chu')**. yInob.

tlhegh yIbej: **QubtaH** pagh **QubtaH…**, ghIq **jang qontaH…**. jan ra'chugh **'el** / **mej** (pagh **Qagh**) yIpoSmoH. **mev** QaptaH mev.

tlhegh yIpoS taH. veb Qu' navDaq ghoS.

## Qu' navDaq yIlan

latlhDaq **Qu' nav** yIpoS (`/board`). ja'chuqmey chaw' 'oH. DIl 'e' motlh naDev tu'lu', tlhegh pong je (pagh **pong Hutlh**).

- yIQach **Qachlu'** mojmeH pin tlheghDaq taH.
- pagh **chu'** yIwuv, **ja'chuq pong…** yIghItlh, 'ej tlheghDaq rarbogh chaw' yIchenmoH.

DaH ja'meH Daq Daghaj 'ej rapbogh Qu' tlha'meH Daq Daghaj.

## nuqDaq qawHaq yIn

**qawHaq** yIpoS (`/memory`). **Hoch Del**Daq yItagh, ghIq **vault ghItlhmey**.

0.8.16-betavo', ja'chuq Dajatlhpu'bogh taH De' vault ghItlhHom mojlaH — **SoH tlhobbe'**. qon autom 'oH 'ej motlh chu'lu'. jang noblu'DI' Qap — jang potlh HeDaq Qapbe'. mI' mach ja'chuq 'ej ja'chuqHom pagh chenmoH motlh; lugh 'oH.

wa'DIch tupDaq ghItlh chu' Daleghbe'laH. nI' 'ej De' law' ja'chuq rInDI' **vault ghItlhmey**Daq yIchegh, pagh nIH yIghItlh. ghoqwI'pu' qawHaq toDlaHtaH wuqtaHvIS.

## potlh ghoqwI'pu' yIbuS

**ghoqwI'pu'** yIpoS (`/agents`). **potlh** yIwIv. lIng pIn'a'Daq Dapongta'bogh cha' ghom lo'wI' 'oH: **jIH QaHwI'** (jajvam) 'ej **pat QanwI'** (EYAS 'oH). taH ghaHpu'; ja'chuqmey ghoS 'ej chegh.

repvamDaq latlh ghoqwI' DachenmoHnISbe'.
