## motlh mIw

1. **ghoqwI'pu'** → ghoqwI' → **Qu' Daq** nav — He `/agents/:id`.
2. nav yIwIv (**Who I am**, **Team description**, **Tools**, **Memory**). **Editor** pagh **Preview**.
3. IDENTITY Deghmey Hutlh pongmeyDaq jaH (pagh chenmoH). **Save**.
4. snapshot poQchugh **History**. cheghmoHpu'DI' nav qach rap snapshot.
