**nuqmeH.** ghoqwI'pu' tetlh pong tetlh 'oH: 'Iv tu'lu', chu'lu''a', 'Iv patlh, 'ar Huch lo'lu'. naDev Dachen, Dachu', DapoSmoH. De' (pat, janmey, QIch, Qu' Daq, He) ghoqwI' navDaq yIn.

## ghorgh yIlo'

- 'Iv ghoqwI' chu', chuplu', pagh Huch tlhoS 'e' yIlegh.
- chu' jeS ghoqwI' — **Create Agent** — pagh taHbogh yIpoSmoH.
- neH **Primary**, **Team**, pagh **Specialist** tetlhmey.
- janmey, QIch, pagh He yIrarmeH pa' ghoqwI' yItu'.

## motlh mIw

1. **ghoqwI'pu'** yIpoSmoH 'em tlheghDaq (**AI**) — He `/agents`.
2. tetlh tInchugh **All / Enabled / Primary / Team / Specialist** yIghIv.
3. tetlh yIchu' (pagh **Create Agent**). navmey: **Configuration**, **Memories**, **Voice**, **Workspace**, **Channels**.
4. yItoD. tetlhDaq pong, jan mI', Huch 'e' yIlegh.

## pat

**He:** `/agents`.  
bIng mu'tlhegh: *ghoqwI'pu' AI, laHmey, jan nobmey je yISeH.*
