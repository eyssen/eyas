**nuqmeH.** nIteb vang Hub SeHwI' 'oH. Hoch Qu' SeghvaD yIwIv: **ghuH** (pa' yIyu'), **chaw'** (chup + wa' yuv), pagh **auto** (yIta' 'ej ret yIja'). Hur 'ej cheghlaHbe'bogh Qu'mey ghuHDaq ngaQ taH. navvam **chaw' loS** tetlh je 'oH — bIwuqpa' Qap loSmoH.

## ghorgh yIlo'

- ja'chuq **chaw' loS**, 'ej nuq loStaH 'e' DaSovbe'taHvIS **chaw'** pagh **lajbe'** DaneH.
- cheghlaHbogh Qu' (teywI' choH, Qul) **auto**Daq Qap DaneH, 'ach ngaQbogh Hur Segh DatlhchoHmoH not.
- Dachaw'pu'DI' taHqa' luj — mevlu'bogh tlhegh SoH poQ wej.
- 'em 'egh Dub mIwmey Dachu'moH pagh Dachu'Ha'moH DaneH (tlhop tIq, ram qech, Forge chupmey, 'egh ghoj, laH lIng).

## motlh mIw

1. retlh navDaq **SeH'egh** yIpoSmoH (**bej** 'ay') — He `/autonomy`. 'egh Dub mIwmey **SeHmey → pat naQ**Daq tu'lu', **nIteb Qap 'ej 'egh Dub** chaw'Daq.
2. **chaw' loS** yIlaD. Hoch tlheghvaD **chaw'** pagh **lajbe'**. De' DaneHchugh, **Qu'vam loS** yItlha' ja'chuqDaq.
3. **cheghlaH** bIngDaq Segh **ghuH / chaw' / auto** yIcher (ngaQbogh Seghmey ghuH Dung ghoSlaHbe').
4. loSbogh Qap taHqa' (lajbe'lu'chugh mev taH). jIH Daq **qImnIS** 'ej ja'chuq **chaw' loS** Degh ngab.

## pat

**tlhopbe'** mIw SeH nIteb vang: Hoch Qu' SeghvaD ghoqwI' 'ar ta'laH, 'ej nuq **ghot chaw'** poQ.

## chutmey

1. 'em 'egh Dub mIwmey **motlh chu'Ha'lu'**; Dachu'moH 'e' DawIv SoH.
2. jIH Daq **qImnIS** tetlhDaq 'ej ja'chuq **chaw' loS** Degh rur 'ang chaw'mey.
3. ghoqwI' IDENTITY'egh choHlaH'a'? YAML SeH 'oH: `autonomy.identitySelfUpdate` (motlh chu'lu'). chu'Ha'lu'chugh, Forge chupmey lo'taHvIS qa' choHmey ghoS.

## chaw' tetlh 'ej patlhmey

**He:** `/autonomy`. bIng pong ja': cheghlaHbe' / Hur Qu'mey **ghuH**Daq ngaQ 'ej ghurlaHbe' — Hub bIng.

### chaw' loS

| SeHwI' | QIj |
|--------|-----|
| **chaw' loS** | loSbogh tlhobmey tetlh |
| *chaw' loS tu'lu'be'.* | tetlh chIm |
| Segh · jan | nuq tlhoblu' |
| meq | qatlh lojmIt vang |
| **Qu'vam loS** | loSbogh Qap / ja'chuqDaq rar |
| **chaw' / lajbe'** | yIwuq — chaw'DI' Qap taHqa' nID |
| *taHqa'laHbe': …* | chaw' wuqlu'pu', 'ach Qap taghqa'be' (taHqa' mevlu') |

**nuq tetlhDaq ghoS.** Hub lojmIt ghot poQchugh SuDqu' pagh Doq jan ra' naDev loS, Hoch nobwI'Daq — CLI (Claude Code, Grok, Kimi) janmey'egh lo'taHvIS ra' DaneHbogh je, 'ej jan rarwI' lo'taHvIS Grok pagh Kimi ra'bogh EYAS janmey je. bejlu'bogh nIteb QapDaq, chaw'vam Qap loSmoH (**chaw' loS**); chaw'lu'DI', Qap taHqa' 'ej chaw'lu'bogh ra' neH wa'logh chaw'lu'.

**Hoch nobwI'Daq wuq rap.** jan rarwI' lo'taHvIS Grok Kimi je SIchbogh EYAS janmey API nobwI'pu' Claude Code je rurqu' wuqlu'. ja'chuq DaQoyDI', pagh He ja'chuqDaq, lojmIt chaw'bogh ra' Qap: ja'chuq Qoylu'bogh navvam patlhmey chu'lu'be', 'ej chaw' poQ per ghajbogh jan naDev loSbe'choH Grok pagh Kimi 'oHmo' pat neH. 'em Qapmey (poH ngaQlu'bogh, ghom, pipeline, pagh Qoylu' per ghajbe'bogh Hoch Qap) patlhmey chu'lu': **ghuH** pagh **chaw'** Seghbogh ra' naDev loS, 'ej lojmIt vIHmoHbogh ra' reH ghot loS, Seghvetlh **auto**Daq tu'lu'DI' je — ngo', ra'vetlh Grok KimiDaq tlhoblu'be'taHvIS Qap. ghoqwI' **janmey** tetlh Hurbogh jan lojmIt tlhoblu'pa' lajQo'lu', vaj naDev ghoS not. lojmIt AI chov QaplaHbe'chugh — lo'laHbogh 'em pat pagh, Huch mevlu', pagh Hoch nID luj —, botlu'be' ra', naDev vIHlu' ([Hub 'ej pegh — Hub noHwI'](/docs/tlh/admin/security-privacy/#security-judge) yIbej).

**Hung Hur Qap tlhobbogh shell ra'.** `security.cliSandbox: auto` tlhej, kernel teywI' Hung Hur wa' ra' Qap 'e' tlhoblaH Claude Code (chovnatlh: `~/.npm` poQbogh ra'). ra'vam reH naDev ghoS 'ej ghot loS — AI noHwI' not, nIteb vang patlh not, Segh patlh 'ar 'ach. meqDaj: *kernel teywI' Hung Hur Qap 'e' tlhob shell ra'. ghot neH chaw'laH; chaw'lu'chugh, wa'logh Hung Hutlh Qap ra'vam neH.* nIteb Qapmey naDev loS. [nobwI'pu' — kernel teywI' Hung](/docs/tlh/ai/providers/#kernel-file-sandbox) yIbej.

**ja'chuqvo' yIwuq.** chaw' loSbogh ra' *chaw' poQ* rur 'anglu', Qapta' rur not, 'ej ja'chuqDaq chaw' chaw' 'ang, **chaw' yInob**, **yIlajQo'**, **chaw' tlhobmey yIpoSmoH** je tlhej. tetlhvam chaw' rap lo' chaw' (nIteb vangDaq chaw'); chaw'vetlh ghajbe'bogh lo'wI'vaD ja'lu': owner pagh admin naDev wuqlaH. [ja'chuqmey — ja'chuqDaq chaw'mey](/docs/tlh/daily/conversations/#approvals-in-the-chat) yIbej.

## SeHmey (nIteb Qap 'ej 'egh Dub chaw')

**SeHmey → pat naQ**Daq **nIteb Qap 'ej 'egh Dub** chaw' tu'lu'. chu'lu'bogh Hoch mIw poHDaq (pagh chu'moHlu'DI') DilmeH pat ra' ngeH, 'ej Hoch motlh chu'Ha'lu':

| SeHwI' | QIj |
|--------|-----|
| **tlhop tIq** | qech nISmoHchugh, tlhop QInmey qon |
| **ram qech** | Hoch ram 'egh qech mIw, QaHwI' QapmeH Dub tu'meH |
| **Forge chupmey** | Qaghmo' jan/laH Dub chup — chaw'lIj poQ taH |
| **'egh ghoj** | lo' chovnatlhmeyvo' mu'tlhegh/He choH chup — chaw'lIj poQ taH |
| **laH lIng** | pIj mIwmeyvo' laH chu' chup — chaw'lIj poQ taH |

Hoch SeHwI' laH ngaQHa'moHwI' neH 'oH — De' Qaw'be'. choHmeH **update Autonomy** chaw' poQ.
