**nuqmeH.** nIteb vang Hub SeHwI' 'oH. Qu' Segh HochvaD **ghuH** (pa' yIyu'), **chaw'** (chup + wa' yuv), pagh **auto** (ta' 'ej ret ja') yIwIv. Hur 'ej cheghlaHbe' Qu'mey **ghuH**Daq ngaQ. navvam **chaw' loS** tetlh je 'oH, Qu' SoH wuqpa' parke'.

## ghorgh yIlo'

- ja'chuq **chaw' loS** 'ej **chaw'** pagh **lajbe'** poQ, nuq parke' DSovbe'taHvIS.
- cheghlaH Qu' (nav choH, tej) **auto**Daq, 'ach Hur ngaQ Segh ghurQo'.
- taHqa' Qapbe' chaw'pu'DI' — che'egh tetlh SoH poQtaH.
- tIq, Forge chupmey, pagh qa' 'egh choH Deghmey chu'/chu'Ha'.

## motlh mIw

1. **SeH'egh** yIpoSmoH 'em tlheghDaq (**bej**) — He `/autonomy`. Deghmey **SeHmey → pat** (nIteb laHmey nav).
2. **chaw' loS** yIlaD. Hoch tetlhDaq **chaw'** pagh **lajbe'**. **Qu'vam loS** ja'chuqDaq jaH.
3. **cheghlaH** bIngDaq Segh **ghuH / chaw' / auto** yIcher (ngaQmey ghuH tlhoSbe').
4. parke'bogh Qu' taHqa'nIS (pagh lajbe'chugh mev). jIH Daq **qImnIS** 'ej ja'chuq Degh narghnIS.

## pat

nIteb vang **bejwI' Hutlh** Qap SeH: tIq, 'egh Dub, qa' choHmey, 'ej nuq **nuv chaw'** poQ.

patlhmey: **ghuH** · **chaw'** · **auto**. ghommey: **cheghlaH** 'ej **Hur / cheghlaHbe' (ngaQ)**. chIm: *chaw' loS tu'lu'be'.*

## motlh

1. HoS mIwmey **motlh HuS** (jIH Daq ghuH yIbej).  
2. chaw'mey jIH Daq **qel 'e' poQ**, ja'chuq **chaw' loS**, 'ej Telegram **Approve / Deny** (rap decide He, jan argv Hutlh).  

3. SeH qa' 'egh choH je nIHlaH (YAMLDaq `autonomy.identitySelfUpdate`).

| yoS | QIj |
|-----|-----|
| tIq / tlhop chovmey | poHDaq « Qu' tu'lu''a'? » |
| qawchoH / briefing | po Dung briefing De' |
| Forge chupmey | qa' / Soul choHmey auto chuplu' |
| ghoj'egh / laH chuqmoH | lo'vo' ghoj (reH chovlaH) |

chu'/chu'Ha' pongmey SeHmey HolmeyDaq yIn (`autonomy-features-card`). Hoch chu' **neH laH Degh** 'oH — De' Qaw'be'.
