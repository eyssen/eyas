**Qu' 'oH.** tej yu' pagh meqvo' web nej Qu' Qap, Halmey chov, 'ej De' chenmoH, latlh poHDaq poSlaHbogh. ghoqwI'pu' lo'qa'laH. Halmey Del DapoQchugh yIlo', ja'chuq wa' neHbe'. Hom nom; tIn law' yu' chu' 'ej law' Halmey pol.

## ghorgh yIlo'

- De' URL Halmey tlhej DapoQ, pat jang neHbe'.
- nom mIw (**tej Hom (nom)**) pagh tIn (**tej tIn (naQ)**) DapoQ.
- Qu' yItlha': **loS** → **nejtaH** → **chovtaH** → **tay'moHtaH** → **rIn**.
- Qu' luj 'ej nIHDaq Qagh mu' DapoQ.

## motlh mIw

1. tlhop **tej** yIpoSmoH (`/research`).
2. **tej chu'** bIngDaq meq yIghItlh (Daq *tej meq yIghItlh…*).
3. **tej Hom (nom)** pagh **tej tIn (naQ)** yIwIv.
4. **yItej**. Qu' poS tetlhDaq nargh 'ej wIvlu'.
5. nIH **tejtaH…** 'ej Dotlh yIloS. Qu' taHbogh cha' lup motlh chu'qa'.
6. **rIn**DI' 'ay'mey 'ej **Halmey** yIlaD. Hal pong yIwIv URL poSmoHlu'.

tetlh chIm: *tej ghItlh tu'lu'be' wej*. wIvbe': *tej ghItlh yIwIv pagh tej chu' yItagh*.

## laHmey

Qu' **loS** tagh, ghIq **nejtaH** (yu' chu' + web nej), **chovtaH** (lI'), **tay'moHtaH** ('ay'mey + latlh chov), ghIq **rIn** pagh **Qagh**.

**'Iv pat vum.** yu' chu', Hal chov, 'ay' ghItlh, latlh chov je EYAS 'em patDaq Qap: wa'DIch **Standard** He patlh, ghIq motlh pat, ghIq API nobwI'pu', ghIq nIteb ra' QaplaHbogh CLImey — He wIv'eghbogh nobwI' not. Hoch ra' nIteb wa'logh ra' 'oH (jan pagh, nobwI' pagh qach qawHaq pagh, wa' mIw), tlha'lu', 'ej Huch toghlu'. [He 'ej Huch — 'em pat](/docs/tlh/ai/routing-budget/#background-model).

**Internet De' De' 'oH, ra' ghobe'.** nej pongmey, Doch machmey, URLmey, nav 'ay'mey, 'ej chaHvo' pat ghItlhbogh 'ay'mey — Hoch ra'vaD Duj pegh per ghajbogh 'ay' qoDDaq patDaq ngeHlu'. 'ay'vetlh qoDDaq De' De' 'oH, ra' ghobe' not — ja'lu' pat, vaj 'ay' SoQmoHlaHbe' jagh nav, 'ej ra'laHbe'.

**pat Hutlhbogh De'mey.** 'em pat ghItlhlaHbe'DI' je rIn De': nIteb 'em ra' QaplaHbogh nobwI' tu'lu'be' (nIteb wej chovlu'bogh Grok neH pagh Kimi neH lIng rur), Huch mevlu', pagh pat ra' luj pagh lo'laHbe'bogh jang nob. vaj wa'DIch meq neH nejlu'; nej mIw tlha' Halmey Seghlu' (Dungmey pollu'); porgh Dung Hal HochvaD wa' 'ay' ghaj — pong, Doch mach, URL je; latlh chov pagh; 'ej pat tu'lu'be'DI' navmey qemlu'be'. De'vetlh 'ay'mey Dung banner 'ang: *Assembled without a model: no background model could synthesize this report (none can run isolated background calls, the budget is stopped, or the call failed), so the top sources are listed with their snippets.* De'meyvetlhvaD ghoqwI' `research` jan `degraded: true` nob. ngo' pat Qagh Qu' **Qagh** rur rInmoH. De'mey tu'lu'bogh choHbe'lu'.

**Hom** yu' latlh mach chu' 'ej tu' mach pol; **tIn** yu' law' chu', yu' HochDaq tu' law' Suq, 'ej Halmey lI' 0.5 rap ghap yoS pol.

nej Brave lo' `brave-search-api-key` pegh tu'lu'chugh; pagh mock (UI chov lI', web teHbe'). pegh [peghmey](/docs/tlh/admin/secrets/)Daq yItoD.

De' rIn yu' pong, **rIn**, Saw' (*Hom* / *tIn*), Hal mI', rIn poH 'ang. porgh pat **'ay'mey** (pong + mu'). **Halmey** `[n]` pong (He) 'ej **N% lI'** tetlh.

Qagh — pat Qagh ghobe'bogh, nej'egh rur: **tej luj** 'ej Qagh mu'. navvamDaq Qaw' pagh ngeH tu'lu'be'.
