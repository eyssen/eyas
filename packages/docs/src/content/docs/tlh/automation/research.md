**Qu' 'oH.** tej yu' pagh meqvo' web nej Qu' Qap, Halmey chov, 'ej De' chenmoH, latlh poHDaq poSlaHbogh. ghoqwI'pu' lo'qa'laH. Halmey Del DapoQchugh yIlo', ja'chuq wa' neHbe'. Hom nom; tIn law' yu' chu' 'ej law' Halmey pol.

## ghorgh yIlo'

- De' URL Halmey tlhej DapoQ, pat jang neHbe'.
- nom mIw (**tej Hom (nom)**) pagh tIn (**tej tIn (naQ)**) DapoQ.
- Qu' yItlha': **loS** → **nejtaH** → **chovtaH** → **tay'moHtaH** → **rIn**.
- Qu' luj 'ej nIHDaq Qagh mu' DapoQ.

## motlh mIw

1. tlhop **tej** yIpoSmoH (`/research`).
2. **tej chu'** bIngDaq meq yIghItlh (Daq *tej meq yIghItlh…*).
3. **tej Hom (nom)** pagh **tej tIn (naQ)** yIwIv.
4. **yItej**. Qu' poS tetlhDaq nargh 'ej wIvlu'.
5. nIH **tejtaH…** 'ej Dotlh yIloS. Qu' taHbogh cha' lup motlh chu'qa'.
6. **rIn**DI' 'ay'mey 'ej **Halmey** yIlaD. Hal pong yIwIv URL poSmoHlu'.

tetlh chIm: *tej ghItlh tu'lu'be' wej*. wIvbe': *tej ghItlh yIwIv pagh tej chu' yItagh*.

## laHmey

Qu' **loS** tagh, ghIq **nejtaH** (yu' chu' + web nej), **chovtaH** (lI'), **tay'moHtaH** ('ay'mey + latlh chov), ghIq **rIn** pagh **Qagh**.

**Hom** yu' latlh mach chu' 'ej tu' mach pol; **tIn** yu' law' chu', yu' HochDaq tu' law' Suq, 'ej Halmey lI' 0.5 rap ghap yoS pol.

nej Brave lo' `brave-search-api-key` pegh tu'lu'chugh; pagh mock (UI chov lI', web teHbe'). pegh [peghmey](/docs/tlh/admin/secrets/)Daq yItoD.

De' rIn yu' pong, **rIn**, Saw' (*Hom* / *tIn*), Hal mI', rIn poH 'ang. porgh pat **'ay'mey** (pong + mu'). **Halmey** `[n]` pong (He) 'ej **N% lI'** tetlh.

Qagh: **tej luj** 'ej Qagh mu'. navvamDaq Qaw' pagh ngeH tu'lu'be'.
