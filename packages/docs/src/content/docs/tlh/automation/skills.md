## nIH laj lojmIt (laH 'Ij)

chenmoHlu' / choHlu' laHmey **nIH lajlu'be'**, qen nIH chov qaw **Qap mI'** 'ej **motlh mI'** 'aqroS SIchbe'chugh. chov QaQ yapbe' 'e' loS, qab laH chupmey yIn tetlhvo' teqlu'.

navDaq nIH chu' / chu'moH choHbe' — lojmIt laH chenmoHvo' nIH laj He neH SeH.

## laH tetlh: Qap He' 'ej chu'Ha' chup

**tetlh** tlhegh (legh retlhDaq): Qap He', So'lu'mey, mung, lo' mI', chu''a' — Hoch laHvaD wa' rap.

### Qap He'

pong rap Daq law'chugh, wa' neH Qaplu' — rar patlh:

| patlh | mung Segh |
|-------|-----------|
| 1 | **lo'wI'** |
| 2 | **chenmoHlu'** |
| 3 | chelmeyvo' **chellu'** |
| 4 | nIH lIngbogh **chellu'** |

Qapbe'bogh Qaw'lu'be' — **So'lu'**bogh tetlhDaq 'ang.

### chu'Ha' chup — vangbe', chup neH

nIH tetlh Hoch chu''a' laH voQ; qab tu'lu'DI', chaw' loS Daq chup chel — **nIH ta'be'**. **chu'Ha'lu' neH — Qaw'lu'be' reH.** SoH DalajDI' neH choHlu'; chu' neH choHlu', ghItlh 'ej qaStaHvIS poH pol.

| Segh | meq |
|------|-----|
| **mung Hutlh** | ghItlh Hutlh |
| **So'lu'** | latlh mung Qapchu' |
| **lo' not** | lo' pagh, 90 jaj Hilbogh |
| **Qong** | lo'ta', 'ach 180 jaj poH lo'be' |

mung Hutlh 'ej So'lu': chaw' loS chupDI' pIj. lo' not 'ej Qong: 30 jajvo' rar laHmey chupbe'; **lo'wI' laHmey** (SoH chenmoHta'bogh) chupHa' reH.

vam nIH laj lojmIt (Dung) rurbe', 'ach chuq: pa' nuq nargh 'e' wuq; vam nuq mej 'e' chup.
