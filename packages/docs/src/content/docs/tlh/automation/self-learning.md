## motlh mIw

2. **chov yItagh**.
3. **laH choH**: loS / chaw' / ghobe'.

5. [laHmey](/docs/tlh/automation/skills/) → **De' tetlh** yIchov.

**'Iv pat ghItlh.** ghoj'egh chupmey, Forge Del chupmey, laH choHvaD laH ghItlh je EYAS 'em patDaq Qap, Hoch wa' nIteb ra': **Heartbeat** He patlh (wa'DIch, ghIq Fallback), ghIq lIng motlh, ghIq API nobwI'pu', ghIq nIteb ra' QaplaHbogh CLImey.
