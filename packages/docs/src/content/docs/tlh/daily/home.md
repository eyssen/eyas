**He:** `/` (nav: **jIH Daq**).

jIH Daq motlh jIH qach teq — DaH raS tu'lu', widget tetlhmey Sun, chelmoH, teq je. Hoch nuv
**motlh raS** tagh. pagh choHlu'taH, wa' Doch bIchoHtaHvIS neH.

## motlh Hutlh widget

| widget | nuq cha' |
|--------|----------|
| **tIq** | SoH poQ, QaptaH, loS, DaHjaj Huch, Qu'mey Qapbe' — Hoch mI' Sam tetlhDaq jaH |
| **qImnIS** | chaw'mey, che'egh taHbe'mey, ghoqwI'pu' loS, poH-tlhejbe' 'ej DaHjaj poH Dochmey, ghuHmey — widgetvo' neH: chaw', lajbe', nIDqa', poSmoH |
| **ghoqwI'pu' QaptaH** | DaH Qaptaobogh ghoqwI'pu' — loS, taHqa', mev |
| **poH nav** | veb poH Qu'mey, wa' Qu' je — **qet Qapbe'pu'** amuy |
| **qen ja'chuqmey** | qen ja'chuqmeylI' |
| **Qu' nav** | SoH wIvbogh Qu' (widget rar) — chaw' widgetvo' neH poSmoH |

latlh Hoch qachvam vumtaH.

## chuplu'bogh lIng

raS Dung sáv motlh, widget Sun. potlh Dochmey (nobwI'pu', Qu'mey, mu'tlheghmey, ghoqwI'pu', wa'
He, De' pa'mey, qawHaq, qonmey, Hop lo', SeH'egh) tIchov 'ej pagh ratlhDI' nargh. wa' chup pagh
Hoch chup So'laH; raSvam Sun ghobe', vaj raS choHtaHvIS QIH laHbe'.

## raS yIchoH

nav baghDaq **jIH Daq yIchoH** yIchu'. choHtaHvIS:

- **widget yIvem** — nav baghDaq lung yISam 'ej yImup.
- **widget rat yIchoH** — lIH baghDaq lung yImup.
- **widget yIteq** — nav baghDaq **×** yIchu'.
- **widget yIchel** — nIHDaq pa' poSchoH; Hoch Sovlu'bogh widgetmey cha', QapHa'bogh patHom
  widgetmey je (qIjHa' chal, vaj nuq tu'lu'chugh Da'legh). Sam widget yIchu' 'e' chel; raS
  bIngDaq chum, ghIq lung yImup 'ej Daq QaQDaq yIlan.

**rIn** yIchu' choHtaHghach botlhmoH. wa' poH tuq'egh mIw ghIq De' yIpol — mIw pol pagh tu'lu'.

**motlh raS yIcheghmoH** (choHtaHvIS neH cha') DaH bIleghbogh breakpoint QIH teq 'ej motlh Hutlh
widget cheghmoH. DaH bIleghbogh raS neH mup — jorwI' pat je tablet pat je (chaq Sun choHta'bogh)
suvbe'.

## chu' widgetmey ghob, teqbe'

raSlI' choHmoH pagh, ghIq motlh widget chelbogh chu' pIn'a' raSlI'Daq **Sun teqbe'**. Sáv
poSchoH: *"chu' widgetmey tu'lu'"* — **yIchel** pagh **ghobe', qatlho'**. **yIchel** chu'
widgetmey Hoch bIng lan; **ghobe', qatlho'** ghobvam reH lajbe'. bISovtaHvIS choHta'bogh raS
mev'e' Sun choHqa'be'.

raSlI' wa'DIch choHbe'chugh, vam SoH QIHbe'. reH motlh Hutlh widget, chu' widgetmey je, Sun.

## Qu' nav widget rar

Qu' nav widget Qu' poQ, cha'meH. widgetvo' neH tIchov; Qu' nav widget law' bIchelmoHlaH, Qu'
Hoch pIm.
