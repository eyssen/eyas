chIm: ja'chuqmey ghommeH Qu' yIchu'.

### motlh ngogh mo'mey (chovnatlh law')

1. **nej mo'mey** bIngDaq lIng tIcher (Odoo chovnatlh / Sor wa'DIch wa' mo', **pongHom** + **qorDu': odoo** je).
2. Dotlh **ghuH** rInpa' **nejqa'**.
3. Qu' foSDaq Qu'vam motlh lo'nISbogh mo'mey tIchov.
4. Qu'Daq ja'chuq yIpoSmoH → nIH **mo'mey** qach rap Qanmey cha' (tlheghDaq je choHlaH).

yIlegh [nej — chovnatlh law' Qan](/docs/tlh/daily/search/#multi-version-pin-which-tree-may-the-agent-use).

## Qu' nav ja' je rar

1. **Segh** yIchu' → motlh ghoqwI' **'ej poQbe' motlh ngogh mo'mey** je **Qu'** yIchu'  
2. **mIw qachmey** tIDel (potlh tetlhmey)  
3. **Qu' nav**Daq ja'chuqmey mIw qachmeyDaq jaH  
4. ja'chuq De'mey **Qu'** / **mIw qach** qachvam rur  
5. ja'chuq **mo'mey** qach Qu' ngogh mo' Qan Suq (nIHlaH)
