### mu'tlhegh QaHwI' ja'chuq

ja'chuq pat qorDu'vaD **mu'tlhegh chenmoHtaHbogh pIn** (Claude, OpenAI, Gemini, Grok, Kimi, …) ngeHpa'. Del: *choHqa'taHbogh mu'tlhegh pIn — ja'chuq pat qorDu'vaD QaQmoHlu'. Qu' Segh yIwIv, choHqa', vaj lo'.*

| SeHwI' | QIj |
|--------|-----|
| meq / ngo' logh | choHqa' DaneHbogh yIDel (*mu'tlhegh ngo' pagh meq yIghItlh…*) |
| **…vaD QaQmoHlu'** | wIv pat qorDu' Degh (tlhegh nobwI'/patvo') |
| Qu' Segh DegHommey | **motlh · ngogh · tej · chov · ghItlh · ghoqwI' · teDwI'mey / legh** — qach 'ej chov tetlh SeH |
| **teDwI' yIchel** | QaHwI' neHvaD De' teDwI'mey (pagh qeng) |
| **ngeH** | QaHwI' ghoqwI' lo'taHvIS choHqa' taH |
| **QaQ N/10** | QaQ chov mI'; **Hutlh: …** Hutlhbogh chov tetlh Del; rInDI' **chov tetlh rIn** |
| **cha' latlh chup (poS + naQ)** | **poS** / **naQ** / **chuplu'** chovnatlhmey tlhob |
| **chuplu'bogh Qav mu'tlhegh** | chelmeH wIv mu'tlhegh |
| **N teDwI'mey qeng** | chel teDwI'mey potlh ja'Daq 'el'a' |
| **lo'** | Qav (pagh Qav) mu'tlhegh potlh ghItlhwI'Daq chel |

### mo'mey (ngogh / Odoo Qan)

|--------|-----|
| chov tetlh | Hoch cherlu'bogh nej mo'mey (pong, chovnatlh, Dotlh, He) |

| **autom** | ja'chuq Qan pagh — Qu' motlh pagh chovnatlh law' `needsPin` chutmey |
| **N Qanlu'** | wIvlu'bogh mo'mey mI' |
| **nej mo'mey yISeH →** | `/search-sources` poSmoH |

**Suq:** Qu'Daq chu' ja'chuqmey, 'ej taHbogh ja'chuqDaq Qu' noblu'DI', Qu' **motlh ngogh mo'mey** qenglu'. naDev reH nIHlaH.

## Qun mIw

Qun mIw **wa' Qu'** qaD law' pat; ghu'mey nuD. ghom SeH loSDIch mIw 'oHbe' — nIH / autom / chIl taH (chay' vumwI' Qu' pImmoH); Qun mIw neH pat law' Qu'vam qaD (laHwI' ghom 'oHbe'). Qun mIw + chIl: Hoch qaDwI' pat yInDaq Qu' pImmoHlaH.

**pat automatically lIngbe'.** wa' pa' Qap; latlh tu'ghach tetlh luDel — SoH lo'.

| potlh | QIj |
|-------|-----|
| **tetlh** | **Settings → Qun mIw** (nav, pat wIv 'em). cha'–vagh nobwI'/pat wIv yIntaH. mI' ramtaHvIS quS poQlu'. |
| **qach** | ja'chuq **ghom SeH** qach Qav wIv (ngab tlhegh 'em): nIH, autom, chIl, vaj **Qun mIw**. Qun mIw wIvchugh nIH/autom/chIl **taH** (vumwI'pu' mIwvetlh qa'). nIH/autom/chIl wIvchugh Qun mIw chu'Ha'lu'. |
| **Huch** | Qun mIw chu'DI' wa'DIch ngeH chaw' qach poQ (tetlh, lo'laHghach ngeb, Huch 'aqroS). veb ngeHmey banner neH. ngeb 'aqroS 'elchugh ngeH botlu' — Settings 'aqroS yIchoH pagh Qun mIw yIchu'Ha'. |
| **pa'mey** | vumwI'pu' ja'chuq vummeH pa'mey pImDaq Qap (git worktree laHchugh). pa' pagh — QaptaH je, tevwI' Hutlh. |
| **QapwI' + tu'ghach** | QapwI' choHlu'bogh tevwI'mey neH ja'chuq pa'meyDaq lIng. latlh tu'ghach **Qun** qachDaq cha'lu' — SoH lo', pat automatically lIngbe'. |

### Settings tetlh

[SeHmey](/docs/tlh/admin/settings/)Daq, pat wIv 'em, **Qun mIw** nav Hoch Qun mIw ja'chuq tetlh 'oH.

| mIw | QIj |
|-----|-----|
| **patmey** | cha'–vagh nobwI'/pat wIv yIntaH. rurbe'nISbe'. |
| **quS** | patmeyvetlh wa'. **mI' ramtaHvIS poQlu'**; motlh chup (vumwI' lujchugh mI' ram taHlaH). quS qaDwI' 'oH, pIn'a' pIm 'oHbe'. |
| **Huch 'aqroS (USD)** | chaw'lu'. ngeb 'aqroS 'elchugh Qapbe'. QaptaHvIS 'aqroS 'elchugh vumwI' rInbe' qIllu', rInbogh wuq. |
| **vumwI' pa'mey qaw (rep)** | pa' pIm repvam rInDI' teqlu' (motlh 72). |

tetlh polchugh QaptaHbogh qet choHbe' — ngeH Hoch tetlh qaw.

ja'chuq nobwI'/pat tlhegh Qun mIw ngeH lo'be' — Settings tetlh Qap.

### Qun mIw yIchu'

1. ja'chuq **ghom SeH** qach yIpoSmoH 'ej **Qun mIw** yIwIv.
2. QIn yIngeH. wa'DIch ngeH Huch chaw' poQ (nuq qaD, USD ngeb, 'aqroS). yIchaw' 'ej yItagh.
3. chu'taHvIS **Qun mIw** banner taH. nIH HeDaq **Qun** qach tu'lu'.
4. **mev** Hoch qaD qIl, wa' vumwI' neH qIlbe'.

### Hutlh 'ej QapwI'

vumwI' Hoch pa'Daj ghaj (git worktree, vum pa' repo 'oHchugh; pagh qaw). vumtaHvIS latlh tevwI' leghbe'.

QapwI' wIvlu'DI' **QapwI' choHlu'bogh tevwI'mey neH** ja'chuq pa'meyDaq qawlu'. latlh pa'DajDaq taH, poH rInDI'. vum pa' Hutlhchugh lIng pagh; QapwI' jangmeyvo' wIvlu' je.

### Qun qach

ja' **Qun** qach tu'lu' Qun mIw chu'taHvIS, **pagh** ja'chuq Qun mIw qet wa' ghajchugh (Qun mIw chu'Ha'lu'chugh taH).

#### nach

DaH mIw, mu'Hom Hoch, USD, poH je.

| mIw | QIj |
|-----|-----|
| **tagh** | tetlh qaw, pa' pIm |
| **qaD** | vumwI'pu' wa' lo'wI' QIn jabbI'ID Qap |
| **chov** | rInbogh chov 'ej wIv |
| **wuq** | QapwI' qawlu' |
| **qeng** | QapwI' tevwI' ja'chuq pa'meyDaq |
| **rIn / luj / qIl** | rIn Dotlh |

vumwI' luj nobwI' Qagh cha' je (API law'chugh).

#### mIw

poH ngutlh: nuq qaS.

| mIw | QIj |
|-----|-----|
| mIw tagh | DaH tetlhvo' qaD |
| vumwI'pu' jabbI'ID | Hoch pat yIn wa' Qu' tagh |
| *pat* rIn / luj | vumwI'vam nIH tagh rIn |
| latlh chov | rInbogh Del luqel 'ej wIv |
| QapwI': *pat* | wuq qawlu' |
| QapwI' pa' qeng | tevwI' ja'chuq pa'meyDaq |
| mIw rIn / luj / qIl | rIn Dotlh |

mIw qawbe'bogh qet qoD poHvo' chenmoHlu'.

#### chay' QapwI' wIwIv

mIwvam wuq Del, wIv mI', **'Iv 'IvvaD wIv**.

| mIw | ghorgh |
|-----|--------|
| **law' wIv** | pat wa' wIv lugh law' latlh. pat **HeghvaD wIvbe'**; Hegh wIv teqlu'. |
| **rap — quS wIv** | cha' pagh law' rap, 'ej quS rapDaq tu'lu'. |
| **rap — nom rIn** | rap, 'ej quS Hutlh pagh rapDaq tu'be'. rapDaq nom rIn Qap. |
| **wa' neH rIn** | latlh luj pagh qIl; rInbogh Qap, latlh chov wIv tu'be'. |

chov Qapbe'chugh vumwI'vam wIv Hutlh. wIv tu'lu'bogh taH.

#### latlh vum luqel

qaD rInDI' rInbogh **wa'** latlh chov (ja'chuq yInbe'). chovwI' HochvaD, qIH pIm Hutlh:

- 'IvvaD wIv
- 1–5: **QaQ**, **naQ**, **QIH**
- latlh vum ghItlh
- tu'ghach motlhbe' (latlh lIngbe' 'e' Har)
- QIH Del

pat nav yIpoSmoHchugh patvam **nIH vum** (chov pa' chen) Qagh je tu'lu'.

#### tu'ghach motlhbe'

**QapwI'be'** tu'ghach tetlh, QapwI' tetlhDaq tu'be'bogh. pa'Daq DapoQchugh SoH lo' — pat automatically lIngbe'.

### puq ja'chuqmey

vumwI' Hoch puq ja'chuq, pong `God <pat>`. tetlhDaq puq ja'chuq cha'laH. Qun mIw **chu'Ha'lu'** — latlh qaD taghbe'.
