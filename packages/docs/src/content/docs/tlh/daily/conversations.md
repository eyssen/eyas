### mu'tlhegh QaHwI' ja'chuq

ja'chuq pat qorDu'vaD **mu'tlhegh chenmoHtaHbogh pIn** (Claude, OpenAI, Gemini, Grok, Kimi, …) ngeHpa'. Del: *choHqa'taHbogh mu'tlhegh pIn — ja'chuq pat qorDu'vaD QaQmoHlu'. Qu' Segh yIwIv, choHqa', vaj lo'.*

| SeHwI' | QIj |
|--------|-----|
| meq / ngo' logh | choHqa' DaneHbogh yIDel (*mu'tlhegh ngo' pagh meq yIghItlh…*) |
| **…vaD QaQmoHlu'** | wIv pat qorDu' Degh (tlhegh nobwI'/patvo') |
| Qu' Segh DegHommey | **motlh · ngogh · tej · chov · ghItlh · ghoqwI' · teDwI'mey / legh** — qach 'ej chov tetlh SeH |
| **teDwI' yIchel** | QaHwI' neHvaD De' teDwI'mey (pagh qeng) |
| **ngeH** | QaHwI' ghoqwI' lo'taHvIS choHqa' taH |
| **QaQ N/10** | QaQ chov mI'; **Hutlh: …** Hutlhbogh chov tetlh Del; rInDI' **chov tetlh rIn** |
| **cha' latlh chup (poS + naQ)** | **poS** / **naQ** / **chuplu'** chovnatlhmey tlhob |
| **chuplu'bogh Qav mu'tlhegh** | chelmeH wIv mu'tlhegh |
| **N teDwI'mey qeng** | chel teDwI'mey potlh ja'Daq 'el'a' |
| **lo'** | Qav (pagh Qav) mu'tlhegh potlh ghItlhwI'Daq chel |

**taH** Qu' / ghoqwI' pat mu'tlheghmeyvaD (wa'logh ja' ngo'mey 'oHbe'), Qu'mey 'ej ghoqwI' SeHDaq [mu'tlhegh pIn](/docs/tlh/ai/prompts/#prompt-coach) yIlo'.

## De' He (ja') {#context-rail-chatter}

qachmey (nIH nach):

**qun · mo'mey · veb · teDwI'mey**

### qun (QInmey / wIvmey)

| SeHwI' | QIj |
|--------|-----|
| **qun** | poH ghItlhHommey 'ej Qu' nav choHmey |
| **Hoch / ghItlhHommey / choHmey** | ghItlhHommey vs De' choHmey wIv |
| **ghItlhHom yIchel…** + **ghItlhHom yIchel** | qawDaq Human ghItlhHom (patvaD ja' mIw 'oHbe') |
| Deghmey **ghItlhHom** / **choH** | 'el Segh |
| **DaHjaj / wa'Hu'** | poH ghom |

### mo'mey (ngogh / Odoo Qan)

ja'chuqvam lo'laHbogh **tetlhlu'bogh nej mo'mey** law' wIv (chov: Odoo 18c + nIH chelmey). wa' tlheghDaq Odoo chovnatlh law' DuD 'e' bot.

| SeHwI' | QIj |
|--------|-----|
| chov tetlh | Hoch cherlu'bogh nej mo'mey (pong, chovnatlh, Dotlh, He) |
| **Hoch yIwIv** / **pe' (autom)** | Hoch mo' yIQan / Qan yIpe' |
| **autom** | ja'chuq Qan pagh — Qu' motlh pagh chovnatlh law' `needsPin` chutmey |
| **N Qanlu'** | wIvlu'bogh mo'mey mI' |
| **nej mo'mey yISeH →** | `/search-sources` poSmoH |

**Suq:** Qu'Daq chu' ja'chuqmey, 'ej taHbogh ja'chuqDaq Qu' noblu'DI', Qu' **motlh ngogh mo'mey** qenglu'. naDev reH nIHlaH.
