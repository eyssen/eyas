**nuqmeH.** ja'chuq Daq ghoqwI' Daja'. QInmey potlh pa'Daq; Qu', mIw, mungmey, ghItlhmey, QaptaH je nIH tlheghDaq. tlheghvam 'oH Qu' nav chovnatlh je — ja' 'ej pipeline wa' qun taH.

## ghorgh yIlo'

- ghoqwI' Qu' ta' 'ej jang, jan ra'mey, vI' je wa' Daq Dalegh DaneH.
- tlheghvam 'Iv ngogh Sor (Odoo mI', chelmey) nejlaH 'e' yIngaQ, 'ej teywI' janmey **vummeH pa'mey** nuq lo'laH.
- ja'chuq 'Iv model lo'taHvIS jang DawIvnIS — model wIvlu'pu'bogh, He nISbe', pagh ghoqwI' motlh (Dung nach model wIvwI').
- laH rap tu'lu' 'ej loS — yIlo', tlheghvamDaq yItlheD, pagh Hoch yIchu'Ha'.
- jan Qappa' nab ghItlh 'ej loS model DaneH (**nab wa'DIch**).
- model law' wa' Qu' qaD DaneH (**Qun mIw**), pagh ghom chovnatlh Hutlh tejwI' rIt juppu' (`run_specialist`).
- nab qum Hoch mIwDaq lengnIS, pagh ngeHpa' ghItlh chenmoH mu'tlhegh DevwI' DaneH.

## motlh mIw

1. tlhegh **juppu'** tetlhvo' **jup** yIpoSmoH (juH ja'chuqDaj), **ja'chuq chu'** yI'uy (**potlh** 'ay'), pagh **Qu' nav** / jIH Daq **qen ja'chuqmey**vo' chovnatlh yIpoSmoH. He `/conversations/:id`.
2. wa'DIch QInpa' **Qu':**, **mIw:**, ghoqwI' je yIcher (ghIq ghoqwI' ngaQ). ghoqwI' wIvwI' **potlh** 'ej **ghom** juppu'lIj tetlh. ngogh Sor law' tetlhlu'chugh **mungmey** yIQach. **vummeH pa'mey** yInuD — tlhegh chu' Qu' tetlh Suq (pagh Qu' Segh tetlh, Qu' tetlh ghajbe'chugh).
3. ghItlhwI'Daq yIghItlh. ghItlh chenmoHnISchugh **mu'tlhegh DevwI'** yIlo'; pu' Degh **nab wa'DIch** 'oH (nab ghItlh 'ej jan Qappa' loS). ghItlhmey yItlhejmoH, pagh Dung nachvo' **nabmey** yItlhejmoH.
4. laH chup chovnatlh cha'lu'chugh **yIlo'**, **DaH ghobe'**, pagh **yIchu'Ha'** yIwIv. yIngeH. jang ghoS, jan tlheghmey yIn tlhej, bIngDaq *nobwI' · model* QIj, 'ej model Qorwagh 'ar tebta' 'angbogh De' tlhegh mach. **mev** QaptaH qIl.

## pat

### 'Iv pat jang {#which-model-answers}
Qapbogh modelDaj pol ja'chuq; QInmey wa' wa' Heqa'lu'be'. model wIvwI'Daq (Dung) chay' DawIv.

- **model wIvlu'pu'bogh.** modelDaq ngaQlu'bogh ja'chuq reH modelvetlh lo'taHvIS jang. model pongbe'bogh jup ghajbe'bogh ja'chuq chu' **wa'DIch QInDaj**Daq lIng motlh Suq — Standard He patlh, pagh motlh nobwI', pagh model ghajbogh wa'DIch Qapbogh nobwI', CLImey je — 'ej ghIq pol. motlh nobwI' pagh He patlhmey DachoHDI', ja'chuqmey tu'lu'bogh vIHbe'. ngo' chenmoHlu'bogh ja'chuqmey pollu'pu'bogh nobwI' model je pol; model pollu'be'bogh ngo' ja'chuq veb QInDaj DaH motlh Suq.
- **ghoqwI' motlh.** jup ghajbogh ja'chuq, ja'chuqHom je, jup model'egh tlha'; pagh ja'chuqvetlh nobbogh ja'chuq model; pagh motlh model, wa'DIch QInDaq ngaQlu'bogh. `run_specialist` / `delegate_to_agent` taghbogh tejwI', `assign_task` noblu'bogh Qu' nav chovnatlh, `create_sub_conversation` chenmoHbogh ja'chuqHom je **nobbogh mIw Qappu'bogh model**Daq Qap — nIH ja'chuq qonlu'bogh SeHvo' cha'logh ghobe'. ghoSmoHvo' poSmoHlu'bogh jup juH ja'chuq jup model tlha', ghoSmoH nobbogh ja'chuq model ghobe'. jup model lo'laHbe'lu'chugh (nobwI'Daj chu'Ha'lu' pagh model chu'Ha'lu'), pollu'bogh pagh motlh modelDaq cheghqa' ja'chuq 'ej jang `agent-binding-unavailable` QIj qon; pong mo' latlh nobwI' wIv EYAS not.
- **He nISbe'** ja'chuq wIv 'oH. Auto cherlu'bogh ja'chuq neH SeHlu': QInDaj Seghlu' 'ej Quick, Standard, Complex, pagh Code He patlhDaq Helu'. nobwI'pu' navDaq **He nISbe' yIchaw'** SeHwI' *chaw'* neH; chu'Ha'taHvIS wIvwI' Doch Hurghlu', 'ej tu'lu'bogh Auto ja'chuq pollu'bogh modelDaj lo' 'ej ja'. ja'chuqmey tu'lu'bogh AutoDaq nIteb vIHlu'be'. [He 'ej Huch](/docs/tlh/ai/routing-budget/#auto-routing) yIlegh.
- **DawIvbogh model So' tammoHlu' not.** wIvwI'Daq DawIvbogh model ghIq lo'laHbe'lu'choHchugh (model pagh nobwI'Daj chu'Ha'lu', pagh nobbe'choH CLI), latlh model lo'taHvIS jang EYAS not: QIn lajQo'lu' 'ej pollu'be', *&lt;nobwI'&gt; / &lt;model&gt; model lo'laHbe'lu': chu'Ha'lu'pu' ghaH pagh nobwI'Daj. ja'chuq nachDaq model wIvwI'Daq latlh model yIwIv, pagh nobwI'pu'Daq yIchu'.* rur ja'. wIvwI' Doq model 'ang, meq rap tlhej, 'ej latlh model DawIvDI' tI'lu'. ja'chuqvetlhDaq 'em Qu' nav Qapmey rap luj.
- **EYAS ngaQbogh modelmey QIj tlhej chegh.** wa'DIch QInDaq ngaQlu'bogh motlh, model wIvwI' tu'lu'pa' ja'chuqmey, ja'chuqHom nobbogh model je: wa' lo'laHbe'lu'DI', motlh model lo'taHvIS jang ja'chuq 'ej ja' (ghuHmoHwI' Degh Qub je). modelDaj cheghDI' nIteb cheghqa'. motlh tu'lu'be'chugh je neH QIn lajQo'lu' (ngoq `model_binding_unavailable`). model cherlu'be'chugh naQ, *model lanlu'be'…* tlhej Qap luj (ngoq `no_model_configured`) 'ej nIDqa'lu'be'.

**'Iv jang.** Hoch QaHwI' jang bIngDaq mach QIj *nobwI' · model* 'ang (*Grok CLI · grok-4* rur). Qub *jangpu' …* ja' 'ej qatlh modelvetlh lo'lu' 'ej Qav mIw ja' je. latlh modelDaq Qav mIw jangchugh, jangbogh model'egh pong QIj. yIntaHbogh jang mIw taghDI' model 'ang; Qun mIw jangmey Qapbogh model 'ang.

**choHDI' De' pollu'.** nobwI' pagh model DachoHDI' ja'chuq De'Daj pol. Hoch mIw ja'chuq naQ pa'Dajvo' ngeH EYAS; nobwI' session Daj pol pagh taHqa' not — Claude Code, Grok CLI, Kimi Code CLI je. [nobwI'pu' — ja'chuq taHtaHghach](/docs/tlh/ai/providers/#conversation-continuity) yIlegh.

**API (rarwI'pu').** `POST /api/v1/conversations` `providerId` + `modelId` pol, Qapbogh nobwI' chu'lu'bogh model ponglu'chugh neH (pagh pagh pollu' 'ej wa'DIch QInDaq motlh ngaQlu'), 'ej chaw'lu'bogh `modelBinding` (`pinned` | `auto` | `inherit`; `inherit` jup poQ, pagh `400 binding_inherit_needs_agent`) 'ej chaw'lu'bogh tagh `effort` laj. `POST /api/v1/projects/:id/conversations` (Qu' navDaq chovnatlh) chut rap lo'. `PATCH /api/v1/conversations/:id` `modelBinding` 'ej `providerId` + `modelId` laj, reH tay' ngeHlu' 'ej chovlu' (Sovbe'lu'bogh pagh chu'Ha'lu'bogh modelvaD `400 model_binding_unavailable`); cha' ngeHbogh PATCH wIvlIj rur per (rarwI' cherlaHbe'bogh per). `GET` `effectiveBinding` (nobwI', model, meq, mIllogh laH je) `autoRoutingEnabled` je nob, 'ej mIw taghDI' rar ja' yIn stream. `POST …/messages`Daq wa' mIwvaD nobwI' + model choH cha' ngeHnIS. ja'chuq Dochmey `sdkSessionId` ngaSbe', 'ej ngeHbogh `PATCH` buSHa'lu'.

### De' chellu'ghach {#context-composition}
ja'chuq Dung tlhegh mach yI'uy — DaH mIwvaD **De' chellu'ghach** qach poSmoH: mIwvam mu'tlheghDaq 'elbogh 'ay' Hoch, chellu'bogh mIw tlha', tInDaj, pe'lu''a', ghItlhDaj tlhol je. wa' mIw neH Del, ja'chuq naQ boq ghobe'.

**turn** Daq QInlIjDaq chellu'bogh ngaS, pat ghItlhDaq ghobe': **turn-time** (DaH jaj poH je) 'ej **memory-recall** (qawqa' 'ay', IDmeyDaj, HuchDaj je). Qap 'ay' jaj poH je ngaSbe' DaH, 'ej ngo' *memory-index* *related-work* je 'ay'mey teqlu'. [qawHaq — chay' qawqa' modelDaq ghoS](/docs/tlh/knowledge/memory/#how-recall-reaches-the-model) yIlegh.

'ay' tInmey mIw jangbogh model tlha' — wIvlu'pu'bogh pagh He nISbe' — vaj 'ay' pe'lu''a' model Qorwagh wuq. Qorwagh tIn model Qu' De' 'ej ghoqwI' ghItlhmey logh law' Suq; mach juH model ja'chuqvaD logh ratlhmoHbogh mu'tlhegh Suq. [mu'tlheghmey — modelvaD tIn cherlu'](/docs/tlh/ai/prompts/#prompt-size) yIlegh. ghoqwI' mIwDaq, mIw Qav model ra' 'ang qach.

**Qorwagh 'ar tebta'.** model Qorwagh 'ar tebta' net 'ang tlhegh:

- **juvlu'.** Qav model ra' mu'tlhegh tIn ja'chugh nobwI', mI'vetlh lo' tlhegh 'ej *juvlu'* ja' Qub (Anthropic 'ej Anthropic rap, OpenAI qorDu' OpenRouter, Kimi API, LM Studio je, Gemini, Claude Code je).
- **ngeblu'.** pagh ngeb 'ang, `~` 'ej *ngeblu'* tlhej: pat ghItlh 'ej mIw tlhej ngeHlu'bogh ja'chuq qun. reH ngeb 'ang Ollama, Grok CLI, Kimi Code CLI je (qawHaqDajvo' lo'qa'bogh 'ay' chIl Ollama; qoD mIwmeyDaj Hoch boq ja' Grok Kimi CLImey).
- **Qorwagh** — wIvlu'bogh model Qorwagh'egh 'oH, Hoch nobwI'Daq: nobwI'pu'Daq modelvaD ponglu'bogh Qorwagh Qap, vaj 1M Qorwagh ghajbogh CLI model 1M lo'. jangbogh model Qorwagh ja'chugh QaptaHwI' (ja' Claude Code), 'oH Qap. CLI ngaQlu'bogh Qorwaghmey (Claude Code 200k, Grok 500k, Kimi 256k) model tetlh Qorwagh ghajbe'DI' neH Qav. Claude Code Fable, Opus, Sonnet, Haiku Dochmey 200k tetlh — pongmeyvam nobbogh QapwI' Qorwagh — QapwI' modelmeyDaj ja'pa' je; QapwI' nobbogh 1M Segh'egh neH (*Opus (1M context)* rur) 1M rur tetlhlu'. latlh modelDaq ja'chuq DavIHDI', SIbI' model chu' Qorwagh lo' tlhegh.
- rItlhmey (50% bIng / 75% bIng / 75% pagh law') Qapla', ghuHmoHwI', Qaw'wI' rItlh je tlha'. Qu' nav *% De'* tlhegh mI' rap lo'. veb mIw ret neH ngo' mIwmey ngebchaj 'ang.

**Hoch 'ay'vaD pegh.** qonlu'bogh Hoch mu'tlhegh 'ay' pegh Degh ghaj:

| Degh | QIj |
|------|-----|
| *N So'lu' · &lt;Seghmey&gt;* | model leghpa' `[EMAIL]` rurbogh Daq pongmey moj De' (*2 So'lu' · QIn Daq, IBAN* rur) |
| *nejlu'be' (EYAS chenmoH)* | qa', chutmey, Qap tlhaq, vummeH pa'mey, jan/laH/ghoqwI' tetlhmey, ghom SeH ra' je rur ngeHlu' |

| Degh pagh | 'ay'vaD pagh qonlu': QInlIj qoDDaq ngeHlu'bogh 'ay'mey (Hoch mIw qawHaq 'ay'), mu'tlheghDaq tu'laHbe'lu'bogh 'ay'mey (nejlu' taH, pat ghItlh latlh tlhej), 'ej So'ghach qonlu'pa' mIwmey |

vay' So'lu'DI', **chellu'bogh rur / pat ngeHlu'bogh rur** SeHwI' 'ang; *pat ngeHlu'bogh rur* 'ay' 'ang, model Suqbogh rur Daq pongmey tlhej. lo'lu'bogh pegh chut mI' pong wa' tlhegh (*pegh chut regex@2/policy@N*), 'ej *qawHaq jan chovnatlh So'lu'bogh: memory_search (2), …* tlhegh De' So'lu'bogh qawHaq jan jangmey tetlh — EYAS jan rarwI' lo'taHvIS Claude Code, Grok, Kimi je Suqbogh jangmey je. [Hub 'ej pegh — nuqDaq So'lu'](/docs/tlh/admin/security-privacy/#where-masking-applies) yIlegh.

**qawHaq nobta'lu'bogh.** modelDaq nuq qawHaq ghoS 'ang 'emwI', 'Iv mIw jang 'ach rap (API nobwI'pu', Claude Code, Grok, Kimi, pagh juH model), Hoch vItvaD wa' tlhegh:

- *&lt;model&gt;vaD chenmoHlu' · &lt;N&gt; tokens Qorwagh* — mu'tlhegh qawHaq Huch je 'Iv modelvaD cherlu'; model Qorwagh Sovbe'chugh EYAS, *Qorwagh Sovbe'lu', 100k tokens lo'lu'*.
- *&lt;hits&gt; qawHaq Doch qawlu'pu' (&lt;expanded&gt; naQ) · &lt;tokens&gt; / &lt;budget&gt; tokens* — QInvamDaq chellu'bogh qawqa' 'ay' (taHbogh ghItlhHommey, QInvaD Suqlu'bogh Dochmey je), 'ar ghItlh naQ Suq, 'ej Qorwaghvam 'aqroSDaj DoS 'ay' tIn ngeblu'bogh. pagh *QInvamvaD qawHaq qawlu'pu'be'*, pagh *qawHaq pollu': &lt;meq&gt;* — SoHvaD jangbe'lu' (A2A ghomwI' pagh Hur ghogh He jang); model Qorwagh Daq tu'lu'be'; naDevvo' qawlaHbogh qawHaq tu'lu'be'; qawqa' luj 'ej poH neH Hev mIw.
- *qawHaq nejmeH: &lt;calls&gt;/&lt;limit&gt; ghogh Qu'vamDaq · &lt;items&gt; Doch laDlu'* — mIwvamDaq model `memory_search` / `memory_expand` / `search_memory` ra'mey'egh, mIw 'aqroS 3 DoS (Hoch nobwI'Daq rap), vay' tu'bogh Qav ra'Daq toghlu'. ra'mey toghlu'pa' qonlu'bogh mIwmey *Doch laDlu'* neH 'ang. jan ra'laHbe'chugh model pagh CLI jan rarwI' chov'egh lujchugh, *qawHaq nejlaHbe': model'e' paQlaHbe' qawHaq janmey*.
- *pat ra'wI' ghItlh: …* (Grok Kimi je neH) — *pat ra'wI' ghItlh rur nobta'lu' ('ollu')*, *pat ra'wI' ghItlh rur ngeHlu' ('ollu'be')*, pagh *QIn qoDDaq ngeHlu'*.

'emwI' tu'lu'pa' qonlu'bogh mIwmeyvaD, pagh mu'tlhegh chellu'be'DI', 'emwI' 'angbe'. latlh Hoch mIw De' rur, motlh 7 jaj pollu', ghIq teqlu'. [bejlaH → De'](/docs/tlh/admin/observability/)Daq **nobwI' qawHaq nobta'ghach** chovnatlh nobwI'pu' nobta'ghach nuD.
