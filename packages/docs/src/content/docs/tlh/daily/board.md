**nuqmeH.** Qu' nav ja'chuqmey vum Daq 'oH. Hoch chovnatlh tlhegh 'oH: mIw qachmeyDaq Damup, Qu' DaghIv, 'ej poSmoHmeH Daja'. Kanban, tetlh, poH tlhegh, De' nav, jIH Daq rap nIH ghom lo'.

## ghorgh yIlo'

- Qu' poS tlheghmey Hoch qachmey rur DaH legh vIneH (pagh Hoch Qu'mey).
- Qu' veb mIw qachDaq yIrIH, chovnatlh yIpin, pagh poH-tlhejbe' / che'egh / chaw' loS yItu'.
- tetlh, poH tlhegh, pagh orkestra Qap De' nav.
- DaHjaj taH, Huch, QaptaH — Qu' nav yImejbe'taHvIS.
- Qu' 'ej mIw qach DachoH ja'chuq chu'.

## motlh mIw

1. **Qu' nav** yIpoSmoH 'em tlheghDaq (**potlh**) — He `/board`.
2. Qu' yIwIv (pagh **All projects**). **Kanban** / **List** / **Timeline** / **Graph** / **Dashboard** yInaw'.
3. chovnatlh chu' mIw qachDaq yImup, pagh ja'chuq poSmoHmeH yIchu'.
4. chu' qachDaq chovnatlh 'e' yIlegh (ja'chuq **Stage** rap). ghIv nIHwI' naw'choHtaHvIS taH.

## pat

**He:** `/board`. Qu'mey mIw qachmey jeDaq chovnatlhmey rur ja'chuqmey tlha'.
