**nuqmeH.** ghItlhmey teDwI' pa' 'oH: PDF, mIllogh, archive, latlh blob SoH (pagh ja'chuq / Sov nav) tayqeq. Daq qonlu' (S3 rap DuH), SuqlaH. Sov wiki 'oHbe', qawHaq ghItlhHom 'oHbe' — teDwI' 'oH.

## ghorgh yIlo'

- PDF, mIllogh, pagh archive ghoqwI' ret poSmoHlaH.
- Hoch teDwI' wa' Daq, Segh ghIv, raS pagh tetlh.
- nobHa' pagh teq, pagh nuqDaq lo'lu' yIlegh.
- Daq pa' vs S3 rap SeH.

## motlh mIw

1. **ghItlhmey** yIpoSmoH 'em tlheghDaq (**De'**) — He `/documents`.
2. teDwI'mey ja'chuq **Attach file**, Sov **Attachments**, pagh chel loghvo' ghoS.
3. **All / Images / PDFs / Archives / Other** yIghIv, pong yInej, raS/tetlh yInaw'.
4. **SeHmey → ghItlhmey** (`/documents-settings`) mI' pagh S3 ngaQmeyvaD.
