**nuqmeH.** ghommey qonmey chel Daq 'oH: ghommey tetlh, nobwI'vo' mu' qon 'ej Del Suq, ta'mey latlh Qu' tlhej. qach **Coming Soon**; bIng nobwI' (Fireflies) rartu'lu' 'ej API ngaQ HutlhDI' SoQ.

## ghorgh yIlo'

- Fireflies (pagh veb nobwI') ghommey EYASDaq tetlh, neH nobwI' qachDaqbe'.
- mu' qon, Del, pagh ta' tetlh Qu' nav tlha' tlhej — chel rInDI'.
- qatlh tetlh chIm: `fireflies-api-key` pegh Hutlh, pagh nablu'bogh banner taH.

## motlh mIw

1. **SeHmey → ghommey** yIpoSmoH ('em tlhegh **SeHmey**, **qach pat** ghom) — He `/meetings`.
2. **Coming Soon** / **Planned** banner yIlaD.
3. Fireflies ngaQ `fireflies-api-key` pegh (pat logh) tu'lu'chugh API tetlhlaH; nav ghIq tetlh cha'. ngaQ Hutlhchugh nobwI' SeHlu'be' 'ej tetlh chIm nob — mu' qon ngebbe'.
4. chIm (*No meetings recorded yet*) pagh tetlhmey pong, jaj, poH, ghom, Dotlh 'e' yIlegh.

## pat

bIng mu': *Meeting recordings, transcripts, and action items.* **Coming Soon** banner. qachmey: Title, Date, Duration, Participants, Status. Fireflies GraphQL ghoch, SSRF-safe fetch. SeHlu'be': tetlh chIm; De' «not configured». ngeb De' tu'lu'be'.
