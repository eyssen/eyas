**Wozu das dient.** Einstellungen (`/settings`) ist der System-Hub: Erscheinungsbild, Sprache, Modellzuweisungen, God-Modus-Kader und die Seitenleisten-Gruppen, die jede andere Admin-Oberfläche öffnen. Stats und Systeminfo leben auf dieser Seite. [Benachrichtigungen](/docs/de/admin/notifications/), [Erweiterungen](/docs/de/admin/extensions/), [Remote-Knoten](/docs/de/admin/nodes/) und [Hände](/docs/de/admin/hands/) sind eigene Seiten, verlinkt aus der Seitenleiste — nicht hier gehostet.

**Route:** `/settings`. Stats: Provider, Modelle, Secrets, User. Systeminfo: Version, Status, Bun, SQLite. Karten: System update, Data port, Appearance, Language (`en` / `hu` / `de` / `es` / `fr` / `tlh`), Model assignments, **God-Modus** (Kader 2–5 Modelle, Vorsitz, Obergrenze — [Gespräche](/docs/de/daily/conversations/#god-modus)), Team agents, Autonomy.

| Gruppe | Links |
|--------|-------|
| General | System, Users, API Keys, Secrets |
| AI & Model | Providers, Prompts, Memory, MCP |
| Modules | Projects, Documents, Search sources, [Benachrichtigungen](/docs/de/admin/notifications/) (`/notifications-settings`), Proactive, Self-learning, [Erweiterungen](/docs/de/admin/extensions/) (`/extensions`) |
| Integrations | [Verbindungen](/docs/de/admin/connections/) (`/connections`) |
| Infrastructure | [Hände](/docs/de/admin/hands/) (`/hands`), [Ingress](/docs/de/admin/ingress/), [Knoten](/docs/de/admin/nodes/) (`/nodes`), Backup, Meetings |
