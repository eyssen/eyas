**Routen:** Einstellungen → Prompts · Gespräch **Prompt Enhancer** · **Prompt coach** bei Projekten / Agenten.

## Schichten

Master (teilweise gesperrt) → Project type → Project → Conversation · plus **Agent System Prompt**. Untere Schichten verfeinern obere.

---

## Prompt Enhancer (Gesprächs-Entwürfe)

Aus dem Composer: optimiert **einmalige** User-Prompts für die **Modellfamilie** des Threads (Task-Typen, Quality-Score, Alternativen). Details: [Gespräche](/docs/de/daily/conversations/).

---

## Prompt Coach (dauerhafte Schichten)

| Scope | Wo | Inhalt |
|-------|-----|--------|
| **Project type** | Projects → Types → Prompt | Wiederverwendbare Typ-Defaults |
| **Project** | Projects → Project → Prompt | Operating Brief des Projekts |
| **Agent system** | Agents → Configuration → System Prompt | Agenten-Protokoll (nicht Stimme, nicht Projekt-Domain) |

Steuerung: Scope-Badge · Send · Quality N/10 · Propose two alternatives · Apply.
