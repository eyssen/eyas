**EYAS** ist eine selbst gehostete persönliche KI-Plattform: Agenten, Speicher, Board, Multi-Kanal-Kommunikation und mehr — auf deiner Maschine, unter deiner Kontrolle.

Dieses Dokumentation richtet sich an **Betreiber und Nutzer**. Tiefe Architektur- und Contributor-Specs liegen im Repo unter `docs/` (siehe [Architektur-Verweis](/docs/de/reference/architecture/)).
