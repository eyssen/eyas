**Route:** `/pipelines`.

Orchestrierte Mehrschritt-Jobs mit Inputs, Gates/Approvals, Artifacts und Run-Historie.

| Konzept | Bedeutung |
|---------|-----------|
| Definition | Benannte Flow-Vorlage |
| Run | Eine Ausführung |
| Input | Ticket-ID, Repo, Optionen |
| Gate | Menschlicher Checkpoint |
| Artifact | Stufen-Ausgabe |

Ticket-to-Code ist eine spezialisierte Pipeline-Oberfläche.
