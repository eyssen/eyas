**Route:** `/tools`.

Tools sind **aufrufbare Fähigkeiten** (Shell, Browser, Dateisystem, HTTP, MCP-Tools, …). Zuweisung am Agenten unter **Configuration → Tools** (kommagetrennte Namen) plus Rechte und Security Gate.

| Konzept | Bedeutung |
|---------|-----------|
| Tool-Name | Stabile ID in Config und Logs |
| Beschreibung | Katalogtext |
| Permissions | CASL / Gate können Aufrufe blocken |
| Sandbox | Manche Tools laufen eingeschränkt |

MCP-Tools: [MCP-Server](/docs/de/ai/mcp/).
