| Befehl | Funktion |
|--------|----------|
| `eyas serve` | Vordergrund |
| `eyas start/stop/restart` | Hintergrund |
| `eyas status/doctor/version` | Status |
| `eyas config validate/reload` | Config |
| `eyas module list/enable/disable` | Module |

Env: `EYAS_PORT`, `EYAS_HOST`, `EYAS_HOME`, `EYAS_INSTALL_ROOT`, Skip/Force Web/Docs-Build.
