## Globale Suche

Query über alle indexierten Quellen · Ergebnisliste · *N results in M files* · Dateivorschau.

## Search Sources (`/search-sources`)

| Feld | Bedeutung |
|------|-----------|
| **Name** | Quellenname |
| **Type** | Art der Quelle |
| **Indexer** | Pipeline |
| **Paths / URLs** | Wurzeln (eine pro Zeile) |
| **Create / Reindex / Delete** | Lebenszyklus |
| **Last indexed** | Zeitstempel |

Status: **idle · indexing · ready · error**.
