| Begriff | Definition |
|---------|------------|
| Agent | Konfigurierter KI-Akteur |
| Primary | Always-on Setup-Teamkollegen |
| Skill | Markdown-Verfahrenspaket |
| Tool | Aufrufbare Fähigkeit |
| Coding surface | Modellunabhängige File-Tools (`read_file`, `edit_file`, …) |
| Worktree | Isolierter Git-Working-Tree für parallele Team-Agenten |
| Verify commands | Lint/Test nach dem Run, vor dem Critic |
| Tool hook | PreToolUse / PostToolUse bei jeder Tool-Ausführung |
| Board | Work-Tracking |
| Gespräch | Chat-Thread |
| Memory-Tier | Working→episodic→vault→archive |
| Memory Block | Gescopter Shared Note (company/agent/team/run) |
| Vault | Langlebiges Markdown-Wissen |
| Provider | LLM-Backend |
| MCP | Model Context Protocol |
| Connection | Benanntes Inventar eines externen Systems |
| Kanal | Externer Messaging-Connector |
| Grounding | Retrieval-Evidenz vor Faktenbehauptungen |
| Hybrid search | FTS + Vektor (RRF) |
| Search Source | Benannter indexierter Baum (Pfad + Label/Version/Family) |
| Code-Quellen-Pin | Conversation- oder Projekt-Auswahl der erlaubten Search Sources |
| needsPin | Tool-Antwort bei mehreren odoo-family-Versionen ohne Pin |
| Prompt Enhancer | Coach für Gesprächs-Entwürfe (modellfamilienbewusst) |
| Prompt Coach | Coach für dauerhafte Project-/Agent-Prompts |
| Forge | Freigegebene Soul/Identity-Änderungen |
| Security Gate | Policy vor Aktionen |
| CASL | Autorisierungsbibliothek |
| Orchestration | Solo/Auto/Deep |
| Effort | Reasoning-Tiefe |
| SLA breach | Overdue/stale-Signal im Proactive-Heartbeat |
| A2A | Agent-to-Agent (Card + Task-Ausführung) |
