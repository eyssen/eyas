---
title: Beállítások áttekintés
description: Rendszer központ — megjelenés, nyelv, kártyák.
---

**Mire való.** A Beállítások (`/settings`) a rendszer központja: megjelenés, nyelv, modell-hozzárendelések, God mód keret, és az oldalsáv-csoportok, amelyek a többi admin felületet nyitják. A statisztika és a rendszerinfo ezen a lapon van. Az [Értesítések](/docs/hu/admin/notifications/), [Bővítmények](/docs/hu/admin/extensions/), [Távoli csomópontok](/docs/hu/admin/nodes/) és [Kezek](/docs/hu/admin/hands/) saját lapok, az oldalsávból — nem itt hostolva.

**Útvonal:** `/settings`. Stats: providerek, modellek, secrettek, userek. System info: version, status, Bun, SQLite.  
Kártyák: System update, Data port, Appearance, Language (`en` / `hu` / `de` / `es` / `fr` / `tlh`), Model assignments, **Isten mód** (God mód keret: 2–5 modell, döntőbíró, plafon — [Beszélgetések](/docs/hu/daily/conversations/#god-mód)), Team agents, Autonomy.  

| Csoport | Linkek |
|---------|--------|
| General | System, Users, API Keys, Secrets |
| AI & Model | Providers, Prompts, Memory, MCP |
| Modules | Projects, Documents, Search sources, [Értesítések](/docs/hu/admin/notifications/) (`/notifications-settings`), Proactive, Self-learning, [Bővítmények](/docs/hu/admin/extensions/) (`/extensions`) |
| Integrations | [Kapcsolatok](/docs/hu/admin/connections/) (`/connections`) |
| Infrastructure | [Kezek](/docs/hu/admin/hands/) (`/hands`), [Ingress](/docs/hu/admin/ingress/), [Csomópontok](/docs/hu/admin/nodes/) (`/nodes`), Backup, Meetings |
