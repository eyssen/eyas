A felhasználói product docs itt véget ér.

Fejlesztőknek a forráskód a mérvadó (`src/modules/…`), plusz:

| Útvonal | Tartalom |
|---------|----------|
| `CHANGELOG.md` | Release history és nagyobb alrendszer-jegyzetek |
| `CLAUDE.md` | Projektkonvenciók és modul-áttekintés |
| `packages/docs/` | Ez a user/admin dokumentációs site |

A mély design draftok és belső tervezési jegyzetek **nincsenek** a nyilvános
repóban.
