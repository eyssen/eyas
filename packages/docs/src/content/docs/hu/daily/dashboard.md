## Szekciók

### Statisztika sáv

| Felirat | Jelentés |
|---------|----------|
| **Needs you / Rád vár** | Emberi beavatkozás (approval, beragadt run, lejárt, …) |
| **Running** | Most futó ágensek / runok |
| **Waiting** | Válaszra vagy approvalra vár |
| **Cost today** | Napi modellköltség (ha van mérés) |

### Autonómia nudge

| Vezérlő | Jelentés |
|---------|----------|
| Szöveg | Opt-in öntanulási / self-improvement loopok (alapból ki) |
| **Review autonomy settings** | Autonómia beállítások |
| **Dismiss** | Nudge elrejtése |

### Ajánlott setup

Hátralévő onboarding lista. A kész elemek eltűnnek.

| Vezérlő | Jelentés |
|---------|----------|
| **Set up** | Kapcsolódó beállítás oldal |
| **Hide this / Hide all** | Egy vagy összes ajánlás elrejtése |
| **Optional** | Nem kötelező az alaphasználathoz |

#### Ajánlás tételek

| Tétel | Mit állíts be |
|-------|----------------|
| **AI models & providers** | Legalább egy provider + modellek |
| **Projects** | Munka/otthon/ügyfél projekt |
| **Base prompts & personality** | Master prompt / personák |
| **Agents & team** | Asszisztensek |
| **Primary agent communication** | Csatorna a primary ágenshez |
| **Directories to index** | Keresési források |
| **Memory vault** | Vault magvetés |
| **Backups** | Első backup |
| **Remote access (Ingress)** | Opcionális alagút |
| **Autonomy & self-improvement** | Opcionális háttér loopok |

### Needs attention

Approval, stuck resume, agent waiting, overdue, due today, proactive alert.

### Pinned / Recent / Now running

Kitűzött beszélgetések (Boardról), legutóbbi chatek, élő ágens aktivitás.

### Morning briefing / Next up

Reggeli összefoglaló (ha a memória reflection be van kapcsolva); következő scheduler jobok.
