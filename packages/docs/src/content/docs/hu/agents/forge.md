**Útvonal:** `/forge`.

A Forge az **ember a loopban** út a mély identity/soul változtatáshoz. Javaslat → te reviewzol → apply vagy reject.

Ha az autonómia tiltja a közvetlen IDENTITY önmódosítást, az ágens Forge javaslatot tesz fájl átírás helyett.

Tipikus vezérlők: összefoglaló, diff, **Approve/Apply**, **Reject**, érintett ágens.
