**Para qué sirve.** La lista de Agentes es la plantilla: quién existe, si está activo, en qué nivel está y cuánto presupuesto ha usado. Aquí creas, activas y abres agentes. El detalle (modelo, herramientas, voz, workspace, canales) vive en la página del agente.

## Cuándo usarlo

- Ver qué agentes están activos, propuestos o sobre presupuesto.
- Un compañero nuevo — **Create Agent** — o abrir uno existente.
- Solo filas **Primary**, **Team** o **Specialist**.
- Vas a enlazar herramientas, voz o un canal y necesitas primero el agente correcto.

## Flujo típico

1. Abre **Agentes** en la barra lateral (**IA**) — ruta `/agents`.
2. Filtra **All / Enabled / Primary / Team / Specialist** si la lista es larga.
3. Haz clic en una fila (o **Create Agent**). Pestañas: **Configuration**, **Memories**, **Voice**, **Workspace**, **Channels**.
4. Guarda. La lista debe mostrar el nombre, el recuento de herramientas y el presupuesto.

## Funciones

**Ruta:** `/agents`. Create Agent. Filtros All/Enabled/Primary/Team/Specialist. Fila: tools, constraints, tokens. Badges Built-in/Custom/Proposed/Pending/Active/Disabled. Tiers Primary/Team/Specialist. Types Assistant…Observer. Tabs Configuration, Memories, Voice, Workspace, Channels.
