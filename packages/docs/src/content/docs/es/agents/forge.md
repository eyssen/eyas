**Para qué sirve.** Forge es el camino con humano en el bucle para cambiar cómo trabajan los agentes. El sistema **propone** (soul, skill o tool); tú **Aprobar y aplicar** o **Rechazar**. La identidad no se reescribe sola salvo que la autonomía permita self-update — el camino seguro por defecto es una propuesta en esta página.

## Cuándo usarlo

- Un agente quiere cambiar IDENTITY / soul y no debe editar el archivo él mismo.
- Hay feedback de skill o herramienta y **Analizar ahora** debe convertirlo en propuestas.
- Ver valor actual vs propuesto, razonamiento y confianza antes de aplicar.
- Un registro de comentarios (useful / friction) sin aplicar nada aún.

## Flujo típico

1. Abre **Forge** en la barra lateral (**IA**) — ruta `/forge`.
2. Quédate en **Propuestas** (o pasa a **Comentarios**). Filtra **Todas / Pendiente / En prueba / Aprobada / Rechazada / Aplicada**.
3. Abre una tarjeta — sobre todo bajo **Soul proposals**. Lee actual vs propuesto, luego **Aprobar y aplicar** o **Rechazar**.
4. El estado debe pasar a **Aplicada** (o **Rechazada**). En **Workspace** del agente, IDENTITY debe coincidir con el texto aplicado.

## Funciones

Subtítulo: *Propuestas de mejora basadas en comentarios para herramientas y habilidades.* **Analizar ahora**. Pestañas **Propuestas** y **Comentarios**. Destinos: **Soul · Habilidad · Herramienta**. Revisión humana Approve/Reject. Obligatorio si no hay self-update directo de IDENTITY.
