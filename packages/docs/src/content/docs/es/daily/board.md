**Para qué sirve.** El Tablero es la superficie de trabajo de las conversaciones. Cada tarjeta es un hilo: la arrastras entre etapas, filtras por proyecto y la abres para hablar. Kanban, lista, línea de tiempo, grafo y panel leen el mismo conjunto filtrado.

## Cuándo usarlo

- Quieres ver todos los hilos abiertos de un proyecto en columnas (o todos los proyectos a la vez).
- Mover trabajo a la siguiente etapa, fijar una tarjeta, o detectar vencidos / atascados / en espera de aprobación.
- Una lista ordenable, una línea de tiempo de vencimientos, o el grafo de una ejecución de orquestación.
- El rendimiento de hoy, el coste y las ejecuciones en vivo sin salir del tablero.
- Vas a empezar una conversación en un proyecto y etapa dados.

## Flujo típico

1. Abre **Tablero** en la barra lateral (**Principal**) — ruta `/board`.
2. Elige un proyecto (o **All projects**). Cambia **Kanban** / **List** / **Timeline** / **Graph** / **Dashboard**.
3. Arrastra una tarjeta a una etapa nueva, o haz clic para abrir la conversación.
4. La tarjeta debe estar en la nueva columna (y el campo **Stage** de la conversación coincidir). Los filtros se conservan al cambiar de vista.

## Funciones

**Ruta:** `/board`. Filtro de proyecto. **New** + título.

## Vistas

Kanban · List · Timeline · Graph · Dashboard. Group by Stage/Priority/Assignee.

## Tarjeta

Title, Pinned, Working/Waiting/Approval/Error, subtasks, context %, overdue, coste, aging.

## Filtros

Stage, Priority, Tags, Active/Done/All, Name, Content. Prioridad Urgent–Low.

## Timeline / Graph / Dashboard

Ventanas 1h–30d. Métricas open/done/running/cost. Grafo Orchestration / Stage flow.
