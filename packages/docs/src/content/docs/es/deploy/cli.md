---
title: Referencia CLI
description: serve, start, stop, doctor, config, module.
---

| Comando | Función |
|---------|---------|
| `eyas serve` | Primer plano |
| `eyas start/stop/restart` | Segundo plano |
| `eyas status/doctor/version` | Estado |
| `eyas config validate/reload` | Config |
| `eyas module list/enable/disable` | Módulos |

Env: `EYAS_PORT`, `EYAS_HOST`, `EYAS_HOME`, `EYAS_INSTALL_ROOT`, skip/force web & docs build.
