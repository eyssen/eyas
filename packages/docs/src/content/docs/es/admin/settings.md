title: Resumen de ajustes
description: Centro del sistema.
---

**Para qué sirve.** Ajustes (`/settings`) es el centro del sistema: apariencia, idioma, asignaciones de modelo, plantilla de Modo Dios y los grupos de la barra lateral que abren el resto de superficies de administración. Las estadísticas y la info de sistema viven en esta página. [Notificaciones](/docs/es/admin/notifications/), [Extensiones](/docs/es/admin/extensions/), [Nodos remotos](/docs/es/admin/nodes/) y [Manos](/docs/es/admin/hands/) son páginas propias, enlazadas desde la barra — no se alojan aquí.

**Ruta:** `/settings`. Stats: providers, modelos, secrets, users. System info: version, status, Bun, SQLite. Tarjetas: update, data port, appearance, language (`en` / `hu` / `de` / `es` / `fr` / `tlh`), model assignments, **Modo Dios** (plantilla 2–5 modelos, presidente, tope — [Conversaciones](/docs/es/daily/conversations/#modo-dios)), team agents, autonomy.

| Grupo | Enlaces |
|-------|---------|
| General | System, Users, API Keys, Secrets |
| AI & Model | Providers, Prompts, Memory, MCP |
| Modules | Projects, Documents, Search sources, [Notificaciones](/docs/es/admin/notifications/) (`/notifications-settings`), Proactive, Self-learning, [Extensiones](/docs/es/admin/extensions/) (`/extensions`) |
| Integrations | [Conexiones](/docs/es/admin/connections/) (`/connections`) |
| Infrastructure | [Manos](/docs/es/admin/hands/) (`/hands`), [Ingress](/docs/es/admin/ingress/), [Nodos](/docs/es/admin/nodes/) (`/nodes`), Backup, Meetings |
