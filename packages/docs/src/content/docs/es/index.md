**EYAS** es una plataforma de IA personal autoalojada: agentes, memoria, tablero, comunicación multicanal y más — en tu máquina, bajo tu control.

Este manual es para **operadores y usuarios**. Las specs de arquitectura profundas viven en `docs/` del repositorio (véase [Arquitectura](/docs/es/reference/architecture/)).
