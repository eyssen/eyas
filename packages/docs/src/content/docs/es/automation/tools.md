**Ruta:** `/tools`.

Tools = acciones invocables (shell, browser, FS, HTTP, MCP…). Asignación en **Configuration → Tools** + permisos y security gate.

| Concepto | Significado |
|----------|-------------|
| Nombre | ID estable |
| Descripción | Catálogo |
| Permissions | CASL / gate pueden bloquear |
| Sandbox | Algunos tools restringidos |

MCP: [Servidores MCP](/docs/es/ai/mcp/).
