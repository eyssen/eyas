**Para qué sirve.** Conocimiento es el wiki **que tú mantienes**: espacios, árbol de páginas, editor rico, versiones, backlinks y adjuntos. El capture no escribe aquí. Para playbooks, runbooks y referencia estable. Memoria/vault es para hechos que el asistente debe recordar solo.

## Cuándo usarlo

- Una página curada (cómo publicamos, guardia, glosario) que editan personas, no una nota extraída del chat.
- Espacios y un árbol, con mover / renombrar / borrar, no un archivo plano de vault.
- Versiones, backlinks o adjuntos en una página.
- Exportar como Markdown.
- El hecho es de **un cliente** — eso es [Wiki de cliente](/docs/es/knowledge/client-wiki/), no aquí.

## Flujo típico

1. Abre **Conocimiento** en la barra lateral (**Contenido**) — clic en la fila para expandir el árbol. Ruta `/knowledge/:pageId`.
2. **New space** si hace falta, luego **New page**. Clic en el título para renombrar.
3. Escribe en el editor. Autoguardado tras una pausa; el badge **vN** avanza.
4. Adjunta archivos en **Attachments**. La página debe verse en el árbol y en la búsqueda global.

## Funciones

**Ruta:** `/knowledge`. Conocimiento **explícito**. Los hechos duraderos automáticos viven en [Memoria](/docs/es/knowledge/memory/). Árbol: New space, Search pages…, New page, Rename / Move to… / Delete. Página: título, vN, AI edited, Export, Width, adjuntos, backlinks, versiones.
