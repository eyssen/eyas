La documentación de usuario termina aquí.

Para implementadores y colaboradores, la fuente de verdad es el código
(`src/modules/…`), más:

| Ruta | Contenido |
|------|-----------|
| `CHANGELOG.md` | Historial de releases y notas de subsistemas |
| `CLAUDE.md` | Convenciones del proyecto y visión de módulos |
| `packages/docs/` | Este sitio de documentación user/admin |

Los borradores de diseño profundos y notas de planificación internas **no** se
publican en el repositorio público.
