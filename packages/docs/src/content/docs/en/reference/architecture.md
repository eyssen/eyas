User-facing product docs stop here.

For implementers and contributors, the source of truth is the codebase itself
(`src/modules/…`), plus:

| Path | Content |
|------|---------|
| `CHANGELOG.md` | Release history and major subsystem notes |
| `CLAUDE.md` | Project conventions and module overview |
| `packages/docs/` | This user/admin documentation site |

Deep design drafts and internal planning notes are **not** published in the
public repository.
