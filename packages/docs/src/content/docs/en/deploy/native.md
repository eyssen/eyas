## Methods

1. `git clone` + `bun install` + `./bin/eyas start`
2. `scripts/install.sh` (macOS/Linux)
3. `scripts/install.ps1` (Windows)

Add `bin/` to `PATH` for the `eyas` command.

Pinned version restore: installer `--version x.y.z-beta` matching backup version.
