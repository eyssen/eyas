**Itinéraire :** `/knowledge`. Navigation en arbre + éditeur enrichi pour les connaissances **explicites** que vous maintenez (contrairement aux niveaux de mémoire automatiques).

Interface typique : arbre latéral, titre de page, barre d'outils de l'éditeur, enregistrer. Préférez Connaissances pour les documents curatés ; Mémoire/Coffre pour les notes à long terme rédigées par les agents.
