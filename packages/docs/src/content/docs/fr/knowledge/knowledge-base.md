**À quoi ça sert.** Connaissances est le wiki **que vous tenez** : espaces, arbre de pages, éditeur riche, versions, backlinks et pièces jointes. Le capture n’écrit pas ici. Pour playbooks, runbooks et référence stable. Mémoire/coffre est pour les faits que l’assistant doit rappeler tout seul.

## Quand l’utiliser

- Une page curatée (comment on ship, astreinte, glossaire) que des humains éditent, pas une note extraite du chat.
- Des espaces et un arbre, avec déplacer / renommer / supprimer, pas un fichier vault plat.
- Versions, backlinks ou pièces jointes sur une page.
- Exporter en Markdown.
- Le fait concerne **un client** — c’est le [Wiki client](/docs/fr/knowledge/client-wiki/), pas ici.

## Déroulement typique

1. Ouvrez **Connaissances** dans la barre latérale (**Contenu**) — cliquez la ligne pour ouvrir l’arbre. Route `/knowledge/:pageId`.
2. **New space** si besoin, puis **New page**. Cliquez le titre pour renommer.
3. Écrivez dans l’éditeur. Autoregistre après une pause ; le badge **vN** avance.
4. Joignez des fichiers sous **Attachments**. La page doit apparaître dans l’arbre et dans la recherche globale.

## Fonctions

**Itinéraire :** `/knowledge`. Connaissance **explicite**. Les faits durables automatiques vivent sous [Mémoire](/docs/fr/knowledge/memory/). Arbre : New space, Search pages…, New page, Rename / Move to… / Delete. Page : titre, vN, AI edited, Export, Width, pièces jointes, backlinks, versions.
