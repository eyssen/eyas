title: Documents
description: Téléversez et indexez des fichiers pour la récupération par les agents.
---

**Itinéraires :** `/documents`, `/documents-settings`.

La zone de téléversement accepte les types de fichiers pris en charge ; les documents sont indexés pour la recherche/récupération dans le chat. La page de paramètres contrôle les options de conservation / indexation (libellés dans les locales Documents).
