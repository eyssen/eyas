---

**Route :** `/research`.

Démarrez une tâche de recherche avec une question ou un sujet ; le système rassemble des sources et produit un rapport que les agents peuvent réutiliser. Les commandes comprennent généralement nouvelle tâche, statut, ouvrir le rapport — les libellés exacts suivent les locales de la page Recherche.
