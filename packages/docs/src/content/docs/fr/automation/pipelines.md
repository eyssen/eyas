**Route :** `/pipelines`.

Les pipelines sont des **tâches orchestrées multi-étapes** (p. ex. ticket → analyse → modifications de code) avec des entrées, des portes et un historique d’exécutions.

| Concept | Signification |
|---------|---------------|
| Définition de pipeline | Modèle de flux nommé |
| Exécution | Une instance d’exécution |
| Entrée | Identifiant de ticket, dépôt, options |
| Porte / approbation | Point de contrôle humain au milieu du flux |
| Artefact | Sortie d’une étape |

Ouvrez une exécution pour le statut de chaque étape. L’interface ticket-to-code peut apparaître comme une page de pipeline spécialisée.
