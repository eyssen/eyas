## Méthodes

1. `git clone` + `bun install` + `./bin/eyas start`
2. `scripts/install.sh` (macOS/Linux)
3. `scripts/install.ps1` (Windows)

Ajoutez `bin/` au `PATH` pour la commande `eyas`.

Restauration d'une version figée : installateur `--version x.y.z-beta` correspondant à la version de la sauvegarde.
