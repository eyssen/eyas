---
title: Import et export de données
description: Importer mémoire, compétences et règles d'espace de travail avec une étape d'approbation.
---

**Emplacement :** Paramètres → carte **Port de données**.

| Capacité | Signification |
|----------|---------------|
| Import | Chemin sur le serveur et/ou téléversement (zip) |
| Cibles | Mémoire (plusieurs niveaux), compétences, règles / identité d'espace de travail d'agent |
| Fusion | **Proposition uniquement** — application après approbation explicite |
| Langue | La mémoire importée conserve la langue source |
| Catégorie des compétences | Importées → **own** |
| Export | Peut indiquer « Bientôt disponible » jusqu'à activation |

Pas pour les dumps complets de la base des secrets — utilisez [Sauvegarde](/docs/fr/admin/backup/) pour une restauration complète.
