**EYAS** est une plateforme d’IA personnelle auto-hébergée : agents, mémoire, tableau, communication multi-canal et plus encore — sur votre machine, sous votre contrôle.

Cette documentation s’adresse aux **opérateurs et utilisateurs**. L’architecture détaillée et les spécifications contributeur se trouvent dans l’arborescence `docs/` du dépôt (voir [Renvoi architecture](/docs/fr/reference/architecture/)).
