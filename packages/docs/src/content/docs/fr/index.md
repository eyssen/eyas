**EYAS** est un système d’exploitation d’IA personnelle auto-hébergé. Des agents nommés, une mémoire durable, un tableau de travail et des canaux tournent sur **votre** machine — pas comme produit dans le nuage d’un autre.

Ce livre s’adresse à l’**opérateur** qui installe et maintient l’instance, et à l’**utilisateur quotidien** qui parle aux agents, suit le travail et lit ce que le système retient. L’architecture détaillée et les spécifications contributeur restent dans l’arborescence `docs/` du dépôt (voir [Renvoi architecture](/docs/fr/reference/architecture/)).

## Comment lire ce livre

La barre latérale suit le produit, pas un découpage scolaire tutoriels / mode d’emploi / référence. Vous avez quatre tâches ; elles vivent dans cet ordre :

| Vous avez besoin de… | Allez ici |
|----------------------|-----------|
| **Apprendre en faisant** | Démarrage : [Premiers pas](/docs/fr/getting-started/), [Assistant de configuration](/docs/fr/setup-wizard/), [Votre première heure](/docs/fr/first-hour/) |
| **Comprendre pourquoi** | [Concepts fondamentaux](/docs/fr/concepts/) et le *À quoi ça sert* en tête de chaque chapitre |
| **Faire un travail** | Travail quotidien, Agents, Compétences et automatisation, Connaissance, Communication, IA, Administration |
| **Retrouver un fait** | Déploiement et CLI, [Glossaire](/docs/fr/reference/glossary/), [FAQ](/docs/fr/reference/faq/), tableaux de champs en bas des pages how-to |

**Parcours recommandé :** [Premiers pas](/docs/fr/getting-started/) → [Assistant de configuration](/docs/fr/setup-wizard/) → **[Votre première heure](/docs/fr/first-hour/)** → [Concepts fondamentaux](/docs/fr/concepts/) → puis le domaine dont vous avez réellement besoin.

Dans le produit, les icônes **?** ouvrent le chapitre correspondant à **`/docs/`** sur le même hôte, dans la langue que vous utilisez.
