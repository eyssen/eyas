ÁttekintésOverview

Személyes AI operációs rendszerPersonal AI operating system

Az EYAS nem egy sima chatbot. Ez egy teljes értékű személyes AI operációs rendszer, amely autonóm módon dolgozik: ágens csapatokat állít össze és orkesztrál párhuzamosan, vezérelheti a böngészőt és az asztalt, 5 rétegű memóriával tanul a tapasztalataiból. Minden beszélgetés egy feladat életciklust jelent — nem egyszerű üzenetváltást, hanem tervezést, végrehajtás-követést és lezárást. EYAS is not a simple chatbot. It is a fully-fledged personal AI operating system that works autonomously: assembling and orchestrating agent teams in parallel, controlling browser and desktop, learning from its experiences through 5-tier memory. Every conversation represents a task lifecycle — not simple messaging, but planning, execution tracking, and closure.

Multi-provider architektúrája 7 AI provider-t támogat — Anthropic Claude, Claude Code, OpenAI GPT, Google Gemini, OpenRouter, Ollama és LM Studio (lokális). A 7 routing tier rendszer automatikusan dönt melyik modellt melyik feladathoz használja: keyword-alapú triage (0 költség) → tier kiválasztás → budget check → fallback lánc. Its multi-provider architecture supports 7 AI providers — Anthropic Claude, Claude Code, OpenAI GPT, Google Gemini, OpenRouter, Ollama, and LM Studio (local). The 7-tier routing system automatically decides which model to use: keyword-based triage (0 cost) → tier selection → budget check → fallback chain.

Teljesen self-hosted, MIT licencelt, egyetlen processzben fut. Az adat és az irányítás mindig a tied marad. Nincs cloud-függőség — minden beágyazott: adatbázis (SQLite/WAL), keresés (Orama FTS+vektor), titkosítás (age/rage). Fully self-hosted, MIT licensed, runs in a single process. Data and control always remain yours. No cloud dependency — everything is embedded: database (SQLite/WAL), search (Orama FTS+vector), encryption (age/rage).

A Forge modul az EYAS evolúciós motorja.
