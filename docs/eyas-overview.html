Mi ez?What is it?

Nem egy chatbot. Egy valódi asszisztens.Not a chatbot. A real assistant.

Az EYAS egy személyes AI operációs rendszer, amely bárhol fut — a saját laptopodtól a felhőig. Bármely AI motort használja: Claude, GPT, Gemini, Grok, Kimi, OpenRouter, Ollama vagy saját kompatibilis endpoint. A kódoló kezek az EYAS-éi: fájl eszközök, git review, worktree izoláció és verify-before-done minden modellnél, nem csak a Claude Code-nál. Indexelt forrásokból idéz (több Odoo-verzió keverése nélkül), külső rendszereket (Odoo, GitHub, Linear…) kapcsolati leltárból hív, és 6 nyelven beszél (en/hu/de/es/fr/tlh). Agent team-eket orkesztrál, vezérli a böngészőt, 5 rétegű memóriával és öntanuló rendszerrel fejlődik. Proaktívan figyeli a feladataidat — SLA-t is —, javasol, és jóváhagyásra parkol ha kell. Nem chatbot: kutat, kódol, dokumentál, kommunikál, ütemez. Az adat és az irányítás mindig a tiéd marad. EYAS is a personal AI operating system that runs anywhere — from your laptop to the cloud. It works with any AI engine: Claude, GPT, Gemini, Grok, Kimi, OpenRouter, Ollama, or your own compatible endpoint. EYAS owns the coding hands: file tools, git review, worktree isolation, and verify-before-done on every model — not only Claude Code. It cites indexed sources (without silently mixing Odoo versions), calls external systems (Odoo, GitHub, Linear…) from a connections inventory, and ships in six languages (en/hu/de/es/fr/tlh). It orchestrates agent teams, drives the browser, and improves itself through 5-tier memory and a self-learning loop. It proactively watches your work — including SLAs — suggests, and parks for approval when needed. Not a chatbot: research, coding, docs, communication, scheduling. Data and control always remain yours.
