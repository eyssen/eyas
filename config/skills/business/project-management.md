# Project Management

## Methodologies

### Agile / Scrum
- Sprint planning: 1-4 week iterations with clear goals
- Daily standups: 15-minute sync on blockers and progress
- Sprint review + retrospective at end of each sprint
- Product backlog grooming: prioritize by business value

### Kanban
- Visualize workflow with columns (To Do, In Progress, Review, Done)
- Limit work-in-progress (WIP) per column
- Pull-based system — start new work only when capacity allows
- Measure lead time and cycle time for continuous improvement

### Waterfall
- Sequential phases: Requirements → Design → Implementation → Testing → Deployment
- Best for fixed-scope projects with well-understood requirements
- Gate reviews between phases

## Planning Essentials
- Define clear project scope and deliverables upfront
- Break down into work packages (WBS — Work Breakdown Structure)
- Identify dependencies and critical path
- Assign owners and deadlines for each task
- Build in buffer time (typically 15-20%) for unknowns

## Tracking and Reporting
- Use burn-down or burn-up charts for sprint progress
- Track velocity (story points per sprint) for forecasting
- Status reports: Red/Amber/Green for stakeholder communication
- Regular risk register updates

## Common Anti-patterns
- Scope creep without re-estimating timeline
- Skipping retrospectives — no learning loop
- Over-planning without execution checkpoints
- Single point of failure — no knowledge sharing
