# Meeting Notes

## Template
```markdown
# Meeting: [Title]
**Date:** YYYY-MM-DD
**Attendees:** [names]
**Duration:** [X minutes]

## Agenda
1. Topic A
2. Topic B
3. Topic C

## Discussion

### Topic A
- Key point discussed
- Decision made: [decision]
- Open question: [question]

### Topic B
- Key point discussed
- Disagreement on X — will revisit next week

## Decisions
- [ ] Decision 1: [description] — decided by [who]
- [ ] Decision 2: [description] — decided by [who]

## Action Items
- [ ] @person: Task description — due YYYY-MM-DD
- [ ] @person: Task description — due YYYY-MM-DD

## Next Meeting
- Date: YYYY-MM-DD
- Topics to cover: [list]
```

## Note-Taking Tips
- Capture decisions and action items in real-time
- Use participants' names for accountability
- Record the reasoning behind decisions, not just the outcome
- Note disagreements and how they were resolved
- Keep it concise — bullet points, not prose

## Standup Notes
Quick format for daily standups:
- **Yesterday:** what was completed
- **Today:** what is planned
- **Blockers:** what is preventing progress
- Keep to 1-2 bullets per category per person

## Retrospective Notes
- What went well (keep doing)
- What didn't go well (change)
- Action items with owners and deadlines
- Follow up on previous retro items first

## Best Practices
- Share notes within 24 hours of the meeting
- Store in a searchable, shared location
- Review action items at the start of the next meeting
- Track action item completion rate
- If no decisions or action items — was the meeting necessary?

## Meeting Optimization
- Always have an agenda before the meeting
- Timeboxed discussions (5 minutes per topic default)
- Designate a note-taker (rotate the role)
- End 5 minutes early to summarize and confirm action items
