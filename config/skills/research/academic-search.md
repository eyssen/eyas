# Academic Search

## Search Platforms
- **Google Scholar:** broadest coverage, citation tracking
- **Semantic Scholar:** AI-powered, free API, good for CS papers
- **arXiv:** preprints for CS, math, physics (free, no paywall)
- **DBLP:** comprehensive CS bibliography
- **IEEE Xplore / ACM DL:** engineering and CS conference proceedings

## Search Techniques
- Use domain-specific terminology (not everyday language)
- Combine keywords with Boolean operators: AND, OR, NOT
- Search by author for known researchers in the field
- Use citation chaining: find a good paper, then check what cites it
- Filter by date range for recent developments

## Evaluating Papers
- **Peer review status:** published in journal/conference > preprint
- **Citation count:** higher is generally better, but normalize by age
- **Venue quality:** top-tier conferences (NeurIPS, ICML, SIGMOD) carry more weight
- **Methodology:** clear experiment design, reproducible results
- **Author credibility:** affiliation, h-index, prior work

## Reading Strategy
1. Read abstract and conclusion first
2. Examine figures and tables
3. Read introduction for context and motivation
4. Deep-dive into methodology only if relevant
5. Check related work section for broader context

## Citation Best Practices
- Always cite primary sources, not summaries
- Use consistent citation format (APA, IEEE, Chicago)
- Include DOI when available for persistent links
- Distinguish between peer-reviewed and preprint sources
- Track citations with a reference manager

## Summarizing Research
- State the research question clearly
- Describe the methodology briefly
- Report key findings with numbers
- Note limitations acknowledged by authors
- Explain practical implications
